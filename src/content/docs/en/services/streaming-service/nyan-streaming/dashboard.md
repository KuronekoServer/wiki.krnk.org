Manage Nyan Streaming stream keys, recordings, analytics, notifications, and team settings from the [web dashboard](https://dash.nyst.live/).

:::note
Settings and usage data are managed **per organization (team)**. After signing in, select the team you want to manage from the switcher in the top-left corner.
:::

![Nyan Streaming dashboard overview](/images/nyan-streaming/dashboard/overview.png)

The home screen shows active streams, total viewers, active stream keys, recording storage use, delivery-server health, and recent activity.

## Guides by Task

| What you want to do                                  | Guide                              |
| ---------------------------------------------------- | ---------------------------------- |
| Manage publish keys and ingest/playback URLs         | [Stream Keys](./stream-keys/)      |
| Find and save cloud recordings                       | [Archives](./archives/)            |
| Manage files delivered through the CDN              | [Media](./media/)                  |
| Check viewers and stream health                      | [Analytics](./analytics/)          |
| Investigate authentication and configuration changes | [Activity](./activity/)           |
| Check streaming-node availability                   | [Server Status](./servers/)        |
| Report JASRAC / NexTone-managed music               | [Music Reports](./music-reports/)  |
| Invite members and manage roles                     | [Users](./users/)                  |
| Configure the organization, billing, and security   | [Settings](./settings/)            |

## Left Sidebar

| Menu                     | Main purpose                                                 |
| ------------------------ | ------------------------------------------------------------ |
| **Dashboard**            | Organization-wide streaming, viewing, and storage overview   |
| **Stream Keys**          | Credentials, connection URLs, and channel output             |
| **Archives**             | Search, play, share, download, and delete recordings         |
| **Media**                | Upload and manage files for CDN delivery                     |
| **Analytics**            | Live and historical metrics, plus authentication logs        |
| **Activity**             | Organization actions and audit history                       |
| **Server Status**        | Online state by region and node                              |
| **Music Reports**        | JASRAC / NexTone music-use reports                           |
| **Users**                | Team members and permissions                                 |
| **Settings**             | Organization, billing, notifications, security, and API keys |

:::tip
Screenshots show the Japanese UI as of August 21, 2026. Areas containing account details or stream secrets have been excluded.
:::
