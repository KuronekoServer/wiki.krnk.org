**Music Reports** records JASRAC- or NexTone-managed music used in a stream. It is available on the **Standard plan and above**.

![Nyan Streaming Music Reports page](/images/nyan-streaming/dashboard/music-reports.png)

## Check before use

Only works whose database entry permits **interactive streaming** may be used through Nyan Streaming. Select **Node01** for a stream that uses JASRAC- or NexTone-managed music and submit a report before or after use. A post-use report must be completed **by the end of the month in which the work was used**.

:::caution
Missing the reporting deadline or submitting inaccurate information may result in an account penalty or additional fee. Verify the work code, title, and use date before submitting.
:::

## JASRAC-managed music

1. Search **JASRAC works** by title, artist, or work code.
2. Select the matching work and add it to the report list.
3. Enter the use date and an optional note.

## NexTone-managed music

1. Open the official **NexTone work search** link from the page.
2. Verify the work code and streaming permission.
3. Manually enter the required code and title. Add the lyricist, composer, and artist when known.
4. Add the work to the list and set its use date.

## Submit and verify history

Add at least one work, review the list, and select **Submit**. Confirm that the society, title, code, artist, use date, and submission time appear under **Past reports**.

:::note
The Free plan shows an upgrade prompt instead of the reporting form.
:::
