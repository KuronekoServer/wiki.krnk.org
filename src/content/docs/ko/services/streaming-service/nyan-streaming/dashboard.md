Nyan Streaming의 스트림 키, 녹화, 분석, 알림, 팀 설정은 [웹 대시보드](https://dash.nyst.live/)에서 관리합니다.

:::note
설정과 이용 현황은 **조직(팀) 단위**로 관리됩니다. 로그인 후 화면 왼쪽 위에서 조작할 팀을 선택하세요.
:::

![Nyan Streaming 대시보드 개요 화면](/images/nyan-streaming/dashboard/overview.png)

첫 화면에서 현재 송출 수, 총 시청자 수, 활성 스트림 키, 녹화 스토리지 사용량, 송출 서버 가동 상태, 최근 액티비티를 확인할 수 있습니다.

## 목적별 가이드

| 하고 싶은 작업                          | 페이지                              |
| --------------------------------------- | ----------------------------------- |
| 송출 키와 송출・시청 URL 관리           | [스트림 키](./stream-keys/)          |
| 클라우드 녹화 검색 및 저장              | [아카이브](./archives/)              |
| CDN으로 배포할 파일 관리                | [미디어](./media/)                   |
| 시청자 수와 송출 상태 확인              | [분석](./analytics/)                 |
| 인증・설정 변경 이력 조사               | [액티비티](./activity/)              |
| 송출 노드 온라인 상태 확인              | [서버 가동 상태](./servers/)         |
| JASRAC / NexTone 관리 악곡 보고         | [악곡 이용 신청](./music-reports/)   |
| 멤버 초대와 권한 관리                   | [사용자](./users/)                   |
| 조직・청구・알림・보안 설정             | [설정](./settings/)                  |

## 왼쪽 사이드바

| 메뉴                  | 주요 용도                             |
| --------------------- | ------------------------------------- |
| **대시보드**          | 조직 전체의 송출・시청・스토리지 개요 |
| **스트림 키**         | 인증 정보, 접속 URL, 채널 송출 관리   |
| **아카이브**          | 녹화 검색, 재생, 공유, 다운로드, 삭제 |
| **미디어**            | CDN용 파일 업로드와 관리              |
| **분석**              | 실시간・시계열 통계와 인증 로그       |
| **액티비티**          | 조직 내 조작 이력과 감사              |
| **서버 가동 상태**    | 리전・노드별 온라인 상태              |
| **악곡 이용 신청**    | JASRAC / NexTone 관리 악곡 이용 보고  |
| **사용자**            | 팀 멤버와 권한 관리                   |
| **설정**              | 조직, 청구, 알림, 보안, API 키        |

:::tip
스크린샷은 2026년 8월 21일 기준 일본어 UI입니다. 계정 정보나 스트림 시크릿이 보이는 영역은 제외했습니다.
:::
