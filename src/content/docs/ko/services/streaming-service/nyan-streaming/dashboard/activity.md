**액티비티**는 조직 내 사용자 조작과 시스템 이벤트를 추적하는 감사 화면입니다.

![Nyan Streaming 액티비티 화면](/images/nyan-streaming/dashboard/activity.png)

## 요약 카드

최근 24시간의 전체 활동, 인증 실패, 스트림 키 생성・삭제, 팀 초대・삭제를 요약합니다. 평소와 다른 증가가 있으면 아래 로그에서 실행자와 시각을 확인하세요.

## 기록되는 주요 이벤트

- 로그인 성공・실패, 로그아웃, 사용자 등록
- 스트림 키 생성, 갱신, 삭제, 재생성
- 녹화 삭제, 재송출 대상 추가・삭제
- API 키 생성・폐기, 알림 테스트
- 요금제 업그레이드・다운그레이드
- 멤버 초대・삭제・역할 변경, 설정 변경

## 로그 조사

이벤트나 사용자를 검색합니다. 각 행에는 이벤트, 실행자, 시각, 수집된 경우 IP 주소가 표시됩니다. 행 메뉴에서 상세 정보를 열거나 검토 완료로 표시할 수 있습니다.

**모두 내보내기** 또는 선택 행 내보내기로 조사 자료를 보관할 수 있습니다. 권한이 있는 사용자는 선택한 로그를 삭제할 수도 있습니다.

:::caution
삭제한 감사 로그는 조사에 사용할 수 없습니다. 일반적인 운영에서는 먼저 내보내 보관한 뒤 삭제하세요.
:::

## 의심스러운 조작을 발견한 경우

1. 실행자, 시각, IP 주소, 대상을 기록합니다.
2. [분석](../analytics/)의 인증 로그와 시각을 대조합니다.
3. 키 유출이 의심되면 [스트림 키](../stream-keys/)를 재생성합니다.
4. [사용자](../users/)와 [설정](../settings/)에서 멤버와 보안을 점검합니다.
