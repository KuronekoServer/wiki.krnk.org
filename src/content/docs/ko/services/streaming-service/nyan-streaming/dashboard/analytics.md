**분석**에서는 현재 조직에서 송출 중인 스트림을 실시간 값과 시계열 데이터로 확인합니다.

![Nyan Streaming 분석 화면](/images/nyan-streaming/dashboard/analytics.png)

## 4개 탭

| 탭             | 확인할 수 있는 내용                                                        |
| -------------- | -------------------------------------------------------------------------- |
| **시청자**     | 활성 스트림, 동시 시청자, 총 인제스트 비트레이트, 실시간 그래프            |
| **시간별**     | 선택한 기간의 시청자 수와 트래픽 시계열                                    |
| **성능**       | 평균 인제스트・이그레스, 키별 순위, 시청 프로토콜 구성                     |
| **인증 로그**  | 최근 송출 인증의 성공・실패, 사용자, IP 주소, 시각                         |

## 시청자와 스트림 상태

실시간 그래프는 몇 초마다 컨트롤 플레인에서 조직 전체 값을 가져옵니다. **스트림 상태**에서는 키별 동시 시청자, 인제스트・이그레스 비트레이트, 사용 중인 시청 프로토콜을 비교할 수 있습니다.

인제스트는 송출자에서 서버로 들어오는 트래픽이고, 이그레스는 서버에서 시청자에게 나가는 트래픽입니다. 인제스트가 0이면 송출 측을, 이그레스가 늘지 않으면 시청 URL과 인증 설정을 확인하세요.

## 성능

인제스트 비트레이트 기준 키 순위, HLS・WHEP・RTSP 연결 구성, 스트림별 평균값, 마지막 갱신 시각을 확인합니다. 인코더나 시청 설정을 바꾸기 전후의 비교에 이용할 수 있습니다.

## 인증 로그

송출 인증의 성공과 실패를 확인합니다. 실패가 반복되면 스트림 키, 인제스트 시크릿, 송출 URL, 송출 원본 IP 규칙을 확인하세요. 시크릿 자체는 로그에 표시되지 않습니다.

:::note
송출 중인 스트림이 없으면 실시간 카드와 순위가 비어 있습니다. 컨트롤 플레인 오류가 새로고침 후에도 계속되면 [문제 해결](../../troubleshooting/)을 확인하세요.
:::
