**아카이브**에는 현재 조직의 스트림 키로 녹화한 과거 방송이 표시됩니다.

![Nyan Streaming 아카이브 화면](/images/nyan-streaming/dashboard/archives.png)

## 녹화를 지원하는 노드

:::caution
**녹화 기능은 Node02에서만 이용할 수 있습니다.** Node01과 Node03에서는 녹화할 수 없습니다.

- **Node01:** JASRAC・NexTone과의 이용 허락 계약상 이 노드의 녹화 데이터를 사용자에게 제공할 수 없기 때문입니다.
- **Node03:** 장시간 송출용 노드이므로 긴 녹화로 서버 저장 공간이 압박받는 것을 방지하기 위해 녹화를 제공하지 않습니다.

녹화가 필요한 송출에서는 Node02를 선택하세요. Node02를 사용하더라도 계약한 요금제에서 녹화 기능을 제공해야 합니다.
:::

## 녹화 만들기

1. **스트림 키**에서 대상 키를 엽니다.
2. **녹화** 탭에서 자동 녹화를 활성화합니다.
3. 송출을 시작합니다.
4. 송출 종료 후 처리가 완료되면 아카이브에 표시됩니다.

녹화 기능, 조직 공용 스토리지, 보존 기간은 요금제에 따라 다릅니다. [요금제・제한・정책](../../plans-and-limits/)과 [노드 선택 방법](../servers/#노드-선택-방법)도 확인하세요.

## 요약 카드

| 항목                  | 의미                                  |
| --------------------- | ------------------------------------- |
| **총 아카이브 수**    | 녹화된 세션 수                        |
| **총 시간**           | 모든 녹화 시간의 합계                 |
| **총 시청자 수**      | 세션별 평균 시청자 수의 누적값        |
| **평균 시간**         | 세션 1건당 평균 녹화 시간             |

**전체 / 최근 7일 / 최근 30일 / 최근 90일**로 기간을 필터링하거나 제목으로 검색할 수 있습니다.

## 녹화 조작

각 행의 메뉴에서 새 탭으로 보기, 다운로드, 직접 링크 복사, 이름 변경, 삭제를 실행합니다. 여러 행을 선택하면 일괄 다운로드 또는 삭제할 수 있고, **모두 내보내기**로 전체 목록을 내보낼 수 있습니다.

이름 변경은 목록・시청 페이지의 표시명과 다운로드 파일명에 반영되지만 직접 링크 URL은 바뀌지 않습니다.

:::caution
삭제한 녹화는 복원할 수 없습니다. 필요한 녹화를 먼저 다운로드하고 제목과 시작 시각을 확인한 뒤 삭제하세요.
:::

## 녹화가 표시되지 않을 때

- 송출 전에 스트림 키에서 녹화를 활성화했는지 확인합니다.
- Node02로 송출했는지 확인합니다. Node01과 Node03의 송출은 녹화되지 않습니다.
- 송출 직후에는 상태가 **처리 중** 또는 **대기 중**이므로 완료될 때까지 기다립니다.
- [미디어](../media/)에서 조직 스토리지 한도 도달 여부를 확인합니다.
- 왼쪽 위 팀 선택기에서 올바른 팀을 선택했는지 확인합니다.
