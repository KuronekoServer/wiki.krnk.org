**미디어**에서는 동영상, 이미지, 기타 파일을 업로드해 CDN으로 배포할 수 있습니다. 녹화와 직접 업로드는 같은 조직 스토리지를 사용합니다.

![Nyan Streaming 미디어 화면](/images/nyan-streaming/dashboard/media.png)

## 조직 스토리지

상단 카드에 사용량과 한도, 남은 용량, 사용률, 녹화와 미디어 각각의 사용량이 표시됩니다. 무제한 요금제는 현재 사용량만 표시합니다.

스토리지가 가득 차면 새 녹화나 업로드가 실패할 수 있습니다. 필요한 파일을 다운로드한 뒤 사용하지 않는 파일을 삭제하거나 요금제를 변경하세요.

## 파일 업로드

1. 업로드 영역을 클릭하거나 파일을 드래그 앤드 드롭합니다.
2. 진행률이 100%가 되고 상태가 **준비 완료**가 될 때까지 기다립니다.
3. 목록에서 이름, 종류, 크기, 상태를 확인합니다.

파일 1개당 한도는 **1GB**입니다. 동영상은 처리 중에 바로 재생되지 않을 수 있습니다. **실패**로 표시되면 파일 크기와 연결 상태를 확인한 뒤 다시 시도하세요.

## 업로드 후 조작

- 동영상은 재생 버튼으로 확인할 수 있습니다.
- 이름 변경 시 확장자는 유지되고 기본 이름만 바뀝니다.
- 이름에는 영문자, 숫자, 하이픈(`-`), 밑줄(`_`)만 사용할 수 있습니다. 공백, 한글・일본어, 기타 기호는 사용할 수 없습니다.
- 필요 없는 파일은 삭제할 수 있습니다.

:::caution
미디어 이름을 바꾸면 파일 URL도 바뀌어 이전 URL은 무효가 됩니다. 기존 URL을 사용한 웹사이트, 공지, 플레이어도 모두 갱신하세요.
:::

:::caution
삭제는 되돌릴 수 없습니다. URL이 더 이상 사용되지 않는지 확인한 뒤 삭제하세요.
:::
