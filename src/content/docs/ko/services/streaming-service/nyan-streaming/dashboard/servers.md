**서버 가동 상태**에서는 송출 노드가 보내는 하트비트를 바탕으로 리전별 온라인 상태를 확인할 수 있습니다.

![Nyan Streaming 서버 가동 상태 화면](/images/nyan-streaming/dashboard/servers.png)

## 화면 읽는 법

상단에 가동 중인 노드 수, 등록된 전체 노드 수, 리전 수, 마지막 갱신 시각이 표시됩니다. 각 리전 카드에는 노드별 **온라인** 또는 **오프라인** 상태가 표시됩니다. 호스트명을 비공개로 설정한 리전은 노드 수만 표시합니다.

**새로고침**으로 최신 상태를 다시 가져옵니다. 상태 API에 연결할 수 없거나 등록 서버가 없으면 해당 메시지가 표시됩니다.

## 노드 선택 방법

송출 내용과 예상 운영 시간에 맞는 노드를 선택하세요.

| 노드       | 주요 용도                            | 특징과 주의 사항                                                                                                                                                 |
| ---------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Node01** | JASRAC・NexTone 관리 악곡 송출       | 관리 악곡을 사용하는 송출용 일본 국내 한정 노드입니다. 사용한 악곡은 대시보드에서 **이용한 달의 말일까지** 반드시 보고해야 합니다. 녹화는 이용할 수 없습니다.      |
| **Node02** | 일반 송출・글로벌 송출               | 세계 각지에 배치된 서버를 이용해 다양한 국가와 지역에 안정적으로 전달하는 기본 노드입니다. 일반・이벤트 송출과 녹화가 필요한 송출에는 Node02를 선택합니다.        |
| **Node03** | 저비트레이트 장시간 송출             | 낮은 비트레이트로 장시간・장기간 연속 송출하기 위한 노드입니다. 24시간 연속 송출 제한 대상이 아니며, 24시간을 넘는 송출에도 이용할 수 있습니다. 녹화는 불가능합니다. |

:::caution
Node01에서 사용한 관리 악곡을 보고하지 않거나 보고 내용에 오류가 있으면 계정 페널티 또는 추가 이용료의 대상이 될 수 있습니다. 자세한 절차는 [악곡 이용 신청](../music-reports/)을 확인하세요.
:::

:::note
Node03에도 요금제별 비트레이트 한도, 스토리지 한도, 이용약관 등 24시간 제한 이외의 조건은 계속 적용됩니다.
:::

:::caution[녹화 기능]
녹화를 지원하는 노드는 Node02뿐입니다. Node01은 JASRAC・NexTone과의 이용 허락 계약상 녹화 데이터를 사용자에게 제공할 수 없습니다. Node03은 장시간 송출용이므로 녹화로 인한 서버 저장 공간 압박을 방지하기 위해 녹화를 지원하지 않습니다. 자세한 내용은 [아카이브](../archives/)를 확인하세요.
:::

## 송출 전・장애 시 확인

1. 사용할 리전이 온라인인지 확인합니다.
2. 오프라인이면 새로고침하고 [KuronekoServer Status](https://status.krnk.org/)도 확인합니다.
3. 다른 리전을 사용할 수 있으면 해당 리전의 송출 URL을 OBS 등에 입력합니다.
4. 송출 시작 후 [분석](../analytics/)에서 인제스트가 들어오는지 확인합니다.

:::note
대시보드에서 노드를 보거나 선택하는 것만으로 연결 대상이 고정되지는 않습니다. 실제 대상은 송출 프로그램에 입력한 URL로 결정됩니다.
:::
