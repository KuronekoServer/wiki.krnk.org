**서버 가동 상태**에서는 송출 노드가 보내는 하트비트를 바탕으로 리전별 온라인 상태를 확인할 수 있습니다.

![Nyan Streaming 서버 가동 상태 화면](/images/nyan-streaming/dashboard/servers.png)

## 화면 읽는 법

상단에 가동 중인 노드 수, 등록된 전체 노드 수, 리전 수, 마지막 갱신 시각이 표시됩니다. 각 리전 카드에는 노드별 **온라인** 또는 **오프라인** 상태가 표시됩니다. 호스트명을 비공개로 설정한 리전은 노드 수만 표시합니다.

**새로고침**으로 최신 상태를 다시 가져옵니다. 상태 API에 연결할 수 없거나 등록 서버가 없으면 해당 메시지가 표시됩니다.

## 노드 선택 방법

Node01·Node02·Node03의 용도, 녹화 지원, 음악 이용 보고, 24시간 제한은 [노드 선택 가이드](../../nodes/)에 정리되어 있습니다. 송출 전에 목적에 맞는 노드를 확인하세요.

## 송출 전・장애 시 확인

1. 사용할 리전이 온라인인지 확인합니다.
2. 오프라인이면 새로고침하고 [KuronekoServer Status](https://status.krnk.org/)도 확인합니다.
3. 다른 리전을 사용할 수 있으면 해당 리전의 송출 URL을 OBS 등에 입력합니다.
4. 송출 시작 후 [분석](../analytics/)에서 인제스트가 들어오는지 확인합니다.

:::note
대시보드에서 노드를 보거나 선택하는 것만으로 연결 대상이 고정되지는 않습니다. 실제 대상은 송출 프로그램에 입력한 URL로 결정됩니다.
:::
