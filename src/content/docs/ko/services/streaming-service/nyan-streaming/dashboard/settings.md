**설정**에서는 조직 전체의 기본 정보, 결제, 알림, 접근 제어, 공개 API 키를 관리합니다. 변경할 수 있는 항목은 현재 역할에 따라 다릅니다.

![Nyan Streaming 설정의 보안 탭](/images/nyan-streaming/dashboard/settings.png)

:::note
스크린샷은 보안 탭의 각 카드를 끝까지 포함합니다. 팀 ID, 청구 정보, 계정 삭제처럼 민감한 영역은 공개 이미지에서 제외했습니다.
:::

## 일반

팀 이름, 팀 URL, 아바타, **기본 언어**를 설정합니다. 기본 언어는 송출 제한 이메일・Webhook・대시보드 알림과 시청자에게 표시되는 경고 동영상에 사용됩니다.

같은 화면에 팀 ID, 소유권 이전, 팀 나가기, 팀 삭제가 있습니다. 신뢰할 수 있는 외부 연동에서 특별히 요구하지 않는 한 팀 ID를 공개하지 마세요.

## 청구

현재 요금제, 결제 수단, 청구 이력을 확인합니다. 유료 요금제로 변경하기 전에 유효한 결제 수단이 필요합니다. 결제 수단의 추가・갱신・삭제는 필요한 권한을 가진 사용자만 수행하세요.

:::caution
청구 탭에는 결제 정보가 표시될 수 있습니다. 화면 공유나 스크린샷 촬영 전에 내용을 확인하세요.
:::

## 알림

### 전송 채널

앱 내, 이메일, Webhook 전송을 선택합니다. Webhook URL 저장 후 일반 형식 또는 Discord embed 형식의 테스트를 보낼 수 있습니다.

### 이벤트

- 스트림 시작・종료
- 인증 실패
- 시청자 마일스톤
- 주간 보고서
- 비트레이트 한도 초과
- 24시간 연속 송출 한도 초과
- 스토리지 한도 도달

Webhook 테스트는 실제 알림을 전송합니다. 운영 채널에서는 담당자와 조율한 뒤 실행하세요.

## 보안

- 2단계 인증을 활성화하거나 비활성화합니다.
- 세션 시간 제한을 선택합니다.
- 송출 원본 IP를 `IP / CIDR` 형식으로 허용・거부합니다.
- API 키 관리 링크와 API 속도 제한을 확인합니다.

IP 규칙은 위에서 아래로 평가되며 처음 일치한 규칙이 적용됩니다. 기본 동작은 허용입니다.

:::note
IP 규칙은 송출(publish)에만 적용됩니다. 공개 시청은 제한하지 않습니다.
:::

## API 키

이름과 선택적 만료일을 지정해 공개 API 키를 만들 수 있습니다. 목록에서 생성일, 마지막 사용일, 만료일을 확인하고 필요 없는 키를 폐기합니다.

:::caution
키 전체 값은 생성 직후 한 번만 표시됩니다. 안전한 비밀 저장소에 보관하고 채팅이나 공개 저장소에 붙여넣지 마세요. 유출되면 즉시 폐기하고 새로 만드세요.
:::

화면에는 인증 헤더와 엔드포인트 설명도 있습니다. 자세한 내용은 [공개 API](../../api/)를 확인하세요.

## 소유권 이전・나가기・삭제

영향 범위가 큰 조작입니다. 대상 팀, 이전할 사용자, 현재 역할, 청구 상태를 확인하고 필요한 스트림 키, 녹화, 감사 로그를 보관한 뒤 진행하세요.
