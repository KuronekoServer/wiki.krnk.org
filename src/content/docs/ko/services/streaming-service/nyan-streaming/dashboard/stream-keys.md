**스트림 키**에서 송출 인증 정보를 생성・교체・삭제하고 시청자에게 제공할 URL을 확인합니다.

![스트림 키 목록과 채널 송출](/images/nyan-streaming/dashboard/stream-keys.png)

## 키 생성

1. 왼쪽 메뉴에서 **스트림 키**를 엽니다.
2. **새 키**를 선택하고 이름과 요금제를 지정합니다.
3. 필요하면 시청 키, 노드, 리전, 메모를 설정합니다.
4. 생성한 키를 열어 송출 URL과 시청 URL을 확인합니다.

시청 키를 비워 두면 무작위로 생성됩니다. 직접 지정할 때는 영숫자, 하이픈(`-`), 언더스코어(`_`)를 사용합니다. 인입용 시크릿은 항상 무작위로 생성됩니다.

어떤 노드를 사용할지 모르겠다면 [노드 선택 가이드](../../nodes/)를 확인하세요. 특별한 요구 사항이 없으면 표준 Node02를 선택합니다.

:::caution
인입용 스트림 키는 비밀번호와 같습니다. 스크린샷이나 송출 화면에 노출하지 말고 제삼자와 공유하지 마세요. 유출된 경우 **키 재생성**으로 기존 값을 즉시 무효화하세요.
:::

## 송출・시청 주소

키의 **개요**에서 선택한 노드에 대응하는 다음 정보를 확인할 수 있습니다.

| 용도 | 표시되는 정보                                                        |
| ---- | -------------------------------------------------------------------- |
| 송출 | RTMP, WebRTC(WHIP), RTSP 인입 URL, 인입 경로                         |
| 시청 | RTSP, RTSPT(TCP), WebRTC(WHEP), HLS, RTMP 시청 URL                   |
| 제한 | 조직 합계 비트레이트・시청자 상한, 녹화, 재송출, 스토리지, 지역 제한 |

대시보드에서 노드를 선택해도 그 노드로 고정되는 것은 아닙니다. OBS나 플레이어에 입력한 URL이 실제 접속 대상을 결정합니다.

## 키 상세 탭

| 탭                | 내용                                         |
| ----------------- | -------------------------------------------- |
| **개요**          | 송출・시청 URL, 요금제, 상한, 이용 가능 기능 |
| **브라우저 송출** | 카메라・마이크・화면을 WebRTC(WHIP)로 송출   |
| **브라우저 시청** | WebRTC(WHEP) 저지연 시청                     |
| **HLS 시청**      | 대시보드에서 `.m3u8` 재생 확인               |
| **통계**          | 키 전체 및 노드별 라이브 통계                |
| **녹화**          | Node02 자동 녹화 활성화 및 이 키의 녹화 목록 |
| **재송출**        | YouTube, Twitch 등 외부 RTMP 대상 관리       |
| **이퀄라이저**    | EQ와 리버브 설정                             |

EQ 프리셋은 Flat / Voice / Music / Bass Boost / Treble Boost, 리버브 프리셋은 Studio / Room / Hall / Cathedral입니다. 변경 사항은 보통 약 3초 안에 시청 측에 반영됩니다.

:::note
녹화 기능은 Node02에서만 이용할 수 있습니다. Node01・Node03이 녹화를 지원하지 않는 이유와 기타 이용 조건은 [아카이브](../archives/#녹화를-지원하는-노드)를 확인하세요.
:::

## 채널 송출

Pro 이상 요금제에서는 조직 공통 시청 URL로 송출할 스트림 키를 전환할 수 있습니다. 시청자 연결을 유지한 채 소스만 교체하는 라이브 스위처입니다.

- 키를 선택하거나 **송출 정지**를 선택합니다.
- 전환은 새 키의 다음 키프레임에 적용되며 최대 1 GOP의 순간 끊김이 발생할 수 있습니다.
- 전환 전후에 동일한 해상도, 프레임레이트, 코덱, 오디오 설정을 사용하세요.

## 키가 일시 정지된 경우

비트레이트 초과, 24시간 연속 송출, 이용약관 위반 시 키 목록에 상태와 해제 예정 시각이 표시됩니다. 경고 화면과 복구 절차는 [문제 해결](../../troubleshooting/)을 확인하세요.
