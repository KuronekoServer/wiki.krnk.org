**사용자**에서는 조직에 참여한 멤버, 권한, 초대 상태, 마지막 활동 시각을 관리합니다.

## 화면 읽는 법

상단 카드에 전체 멤버 수, 관리자 수, 대기 중인 초대 수가 표시됩니다. **전체 멤버**에서 이름이나 이메일을 검색하고 역할, 상태, 마지막 활동 시각을 확인할 수 있습니다.

:::note
이 페이지는 멤버의 이름과 이메일 주소를 포함하므로 스크린샷을 공개하지 않습니다. 화면 구성과 조작은 아래에서 설명합니다.
:::

## 역할

| 역할             | 권한의 기준                                            |
| ---------------- | ----------------------------------------------------- |
| **소유자**       | 청구, 소유권 이전, 팀 삭제를 포함한 모든 권한         |
| **부소유자**     | 소유권 이전과 팀 삭제를 제외한 대부분의 조작          |
| **멤버**         | 스트림 키와 분석에 대한 읽기 전용 접근                |

작업에 필요한 최소한의 역할을 부여하세요. 송출이나 알림 설정을 변경해야 하는 사람에게만 관리자 역할을 부여합니다.

## 멤버 초대

1. **멤버 초대**를 누릅니다.
2. 이메일 주소와 역할을 지정합니다.
3. 상태가 **초대됨**으로 표시되는지 확인합니다.
4. 상대방이 참여하면 **활성**으로 바뀝니다.

대기 중인 초대는 메뉴에서 다시 보내거나 취소할 수 있습니다.

## 역할 변경과 삭제

각 멤버의 메뉴에서 역할을 변경할 수 있습니다. 멤버를 삭제하면 해당 사용자는 조직의 스트림 키, 녹화, 분석, 설정에 접근할 수 없게 됩니다.

:::caution
담당 변경이나 퇴사 시에는 멤버 삭제뿐 아니라 공유한 스트림 키 재생성과 API 키 폐기도 검토하세요. 마지막 소유자는 삭제하지 마세요.
:::
