# 시작 가이드

이 페이지에서는 Nyan Streaming 대시보드에서 스트림 키를 만들고 OBS Studio에서 송출한 뒤 브라우저 또는 VRChat에서 재생을 확인하는 과정을 설명합니다.

## 준비 사항

- [Nyan Streaming 대시보드](https://nyst.live/)에 로그인할 수 있는 계정
- RTMP로 H.264 / AAC 송출이 가능한 OBS Studio 등의 소프트웨어
- 송출을 관리할 조직(팀)

로그인한 뒤 왼쪽 위의 팀 전환 메뉴에서 작업할 조직을 선택하세요. 요금제 상한, 스트림 키, 시청 URL, 녹화는 조직 단위로 관리됩니다.

## 1. 스트림 키 만들기

1. 왼쪽 메뉴에서 **스트림 키**를 엽니다.
2. **새 스트림 키**를 선택합니다.
3. 알아보기 쉬운 이름과 요금제를 지정합니다. 필요하면 노드, 리전, 시청 키, 메모도 설정합니다.
4. 생성한 키를 열고 **개요** 탭을 표시합니다.

:::note
**송출용 스트림 키(시크릿)**와 시청 URL에 포함되는 **시청 키**는 서로 다른 값입니다. 시청자에게는 시청 URL만 공유하세요.
:::

## 2. 송출 정보를 확인하기

### 노드 선택 방법

스트림 키를 만들 때 송출 목적에 맞는 노드를 선택합니다.

| 송출 내용·조건 | 선택할 노드 |
| --- | --- |
| JASRAC 또는 NexTone이 관리하는 음악을 사용 | **Node01** |
| 일반 송출, 이벤트, 전 세계 송출 또는 녹화 이용 | **Node02** |
| 낮은 비트레이트로 24시간을 초과하는 장시간 송출 | **Node03** |

:::tip
특별한 조건이 없고 어떤 노드를 사용할지 모르겠다면 **Node02**를 선택하세요. 녹화를 이용할 수 있는 노드도 Node02뿐입니다.
:::

음악 이용 보고, 녹화 지원, 송출 시간 등의 차이는 [노드 선택 가이드](/ko/services/streaming-service/nyan-streaming/nodes/)에서 자세히 설명합니다.

노드를 선택한 다음 개요 탭에서 사용할 서버의 다음 두 값을 복사합니다.

| OBS 항목  | 대시보드에서 복사할 값    |
| --------- | ------------------------- |
| 서버      | RTMP 인제스트 URL         |
| 스트림 키 | 송출용 스트림 키 / 시크릿 |

:::caution
송출용 스트림 키는 비밀번호처럼 취급하세요. 다른 사람에게 보내거나 방송 화면·스크린샷에 노출하지 마세요. 유출된 경우 대시보드에서 키를 재생성하세요.
:::

## 3. OBS Studio 설정하기

OBS Studio에서 **설정 → 방송**을 열고 다음과 같이 설정합니다.

| 항목              | 설정                                                                      |
| ----------------- | ------------------------------------------------------------------------- |
| 서비스            | 사용자 지정                                                               |
| 서버              | 대시보드의 RTMP URL                                                       |
| 스트림 키         | 대시보드의 송출용 시크릿                                                  |
| 비디오 인코더     | H.264 (AVC)                                                               |
| 오디오 인코더     | AAC                                                                       |
| 레이트 제어       | CBR 권장                                                                  |
| 비디오 비트레이트 | 우선 1,000~1,500 kbps 정도로 시작하고 조직 합계를 요금제 상한 이내로 유지 |
| 키프레임 간격     | 1초 권장                                                                  |

서버는 영상을 재인코딩하지 않습니다. 지원하지 않는 영상 또는 음성 코덱을 사용하면 연결되어도 시청 측에서 재생되지 않을 수 있습니다. 음성은 AAC가 표준입니다. **LPCM 송출은 RTSP에서만 가능하며, LPCM 송출을 RTSP 이외의 방식으로 시청하면 음성은 AAC로 제공됩니다.** 미리 설정된 구성은 [저지연 OBS 프로파일](/ko/services/streaming-service/nyan-streaming/obs-profile/)에서 배포하고 있습니다.

:::caution
입력 비트레이트 상한은 스트림별 상한이 아니라 **조직에서 동시에 송출 중인 모든 스트림의 합계**에 적용됩니다.
:::

## 4. 송출을 시작하고 확인하기

1. OBS Studio에서 **방송 시작**을 누릅니다.
2. 대시보드에서 해당 키가 활성화되고 입력 비트레이트가 표시되는지 확인합니다.
3. 키 상세의 **브라우저 시청** 또는 **HLS 시청**에서 영상과 음성을 확인합니다.
4. VRChat에서 사용할 경우 개요 탭의 RTSP / RTSPT URL을 AVPro 호환 플레이어에 입력합니다.

저지연을 우선하면 RTSP 또는 WebRTC (WHEP), 브라우저 호환성을 우선하면 HLS가 적합합니다. VRChat 플레이어별 설정은 [비디오 플레이어 설정/확인](/ko/services/streaming-service/nyan-streaming/video-player-settings/)을 확인하세요.

## 5. 송출 종료하기

OBS Studio에서 **방송 종료**를 누르고 대시보드에서 키가 비활성 상태가 되었는지 확인합니다. 녹화를 활성화했다면 처리 완료 후 **아카이브**에서 재생하거나 다운로드할 수 있습니다.

## 브라우저만으로 송출하기

키 상세의 **브라우저 송출** 탭에서는 카메라, 마이크, 화면 공유를 WebRTC (WHIP)로 직접 송출할 수 있습니다. Edge / Chrome / Firefox 등 HTTPS 지원 브라우저에서 필요한 장치 접근을 허용한 뒤 송출을 시작하세요.

## 문제가 발생한 경우

송출이 시작되지 않거나 영상·음성이 나오지 않거나 제한 화면으로 전환되는 경우 [문제 해결](/ko/services/streaming-service/nyan-streaming/troubleshooting/)을 확인하세요.
