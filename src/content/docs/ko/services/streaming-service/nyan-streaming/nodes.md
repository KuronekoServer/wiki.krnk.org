# 서비스와 노드 선택

용도에 맞는 서비스를 선택하고 실제 송출 및 시청 URL은 해당 서비스 안내 또는 대시보드에서 확인하세요.

| 서비스 | 호스트 | 확인 사항 |
| --- | --- | --- |
| Nyan Streaming 무료 서버 | `free.nyst.live` | 무료 서버입니다. 이용 방법은 공식 사이트의 도구를 확인하세요. |
| Nyan Streaming 일반 서버 | `stream.nyst.live` | 대시보드에 표시된 송출 및 시청 URL을 사용하세요. |
| Nyan Streaming Enterprise 노드 | 맞춤 | 맞춤 구성입니다. 계약 안내 또는 대시보드에서 호스트와 이용 조건을 확인하세요. |
| Nyan Streaming Japan | `stream.jp.nyst.live` | 일본 서비스입니다. 대상 악곡의 이용 조건과 보고 방법은 공식 사이트와 음악 이용 보고를 확인하세요. |

녹화, 송출 시간, 이용 가능 지역은 서비스·요금제·계약에 따라 다릅니다. 녹화나 장시간 송출 전에 대시보드 또는 운영진에게 확인하세요.

VRChat에는 시청 URL의 호스트 이름을 등록합니다. 맞춤 노드는 표시된 URL을 확인하세요.

- [Nyan Streaming](https://nyst.live/)
- [Nyan Streaming Japan](https://jp.nyst.live/)
- [VRChat](../vrchat-world-domains/)
