# 문제 해결

먼저 대시보드에서 스트림 키 목록과 키 상세를 열고 키 상태, 입력 비트레이트, 선택한 노드·리전, 제한 배너를 확인하세요.

## 증상별 확인 사항

| 증상                             | 먼저 확인할 내용                                                                                           |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 송출이 시작되지 않음             | RTMP URL과 송출용 시크릿, 노드 상태, 키의 제한 배너                                                        |
| 영상이 나오지 않음               | 비디오 코덱이 H.264 (AVC)인지 확인                                                                         |
| 음성이 나오지 않음               | 오디오 코덱이 AAC인지 확인. WebRTC는 Opus를 사용하며 LPCM은 RTSP 송출·시청에서만 이용 가능                |
| 브라우저에서 HLS가 재생되지 않음 | URL이 `.m3u8`인지, Safari 이외에서는 hls.js 호환 플레이어를 사용하는지 확인                                |
| VRChat에서 재생되지 않음         | AVPro 호환 플레이어인지, RTSP / RTSPT URL을 사용하는지, Stream Mode / Low Latency가 활성화되어 있는지 확인 |
| 지연이 큼                        | 가능하면 HLS 대신 RTSP 또는 WebRTC (WHEP) 사용                                                             |
| 송출이 도중에 끊김               | 비트레이트, 24시간 연속 송출, 약관 위반에 관한 제한 배너와 알림 확인                                       |

## 제한 화면이 표시된 경우

비트레이트, 24시간 연속 송출, 이용약관 위반으로 송출이 정지되면 정상 송출 대신 사유별 경고 화면이 시청자에게 표시됩니다. 대시보드의 키 목록에는 사유가 표시되며 자동 제한에는 해제 예정 시각도 표시됩니다.

:::note
경고 화면과 이메일·Webhook·앱 내 알림의 언어는 **설정 → 일반 → 기본 언어**에서 정합니다. 일본어를 선택하면 일본어 이미지가, 그 밖의 언어에서는 영어 이미지가 표시됩니다. 현재 한국어 전용 경고 이미지는 제공되지 않으므로 영어 화면이 사용됩니다.
:::

### 24시간 이상 연속 송출

24시간 제한이 활성화된 노드에서 하나의 publish 세션이 24시간 연속으로 실행된 경우 적용됩니다. 해당 송출을 중지하고 **조직의 모든 스트림 키를 하루 동안** 차단합니다. 다시 연결하면 연속 시간은 새 세션으로 계산됩니다. **Node03은 이 제한의 대상이 아닙니다.**

![24시간 이상 연속 송출 제한 화면(영어)](https://cdn.krnk.org/kuronekoserver/nyst/warning/24h-en.png)

**해결 방법**

1. 대시보드에서 해제 예정 시각을 확인합니다.
2. 제한이 해제될 때까지는 송출을 재개할 수 없습니다.
3. 해제 후 새 세션으로 송출을 시작합니다.
4. 낮은 비트레이트로 24시간을 넘는 연속 송출에는 Node03을 사용합니다. 필요한 운영 조건이 Node03의 용도와 맞지 않으면 사전에 [문의](https://krnk.org/contact/)해 주세요.

### 입력 비트레이트 상한 초과

조직에서 동시에 송출 중인 모든 스트림의 입력 비트레이트 합계가 요금제 상한을 **10분 이상** 계속 초과한 경우 적용됩니다. 합계가 상한 이하가 될 때까지 최근에 시작된 송출부터 정지되며, 정지 대상 키는 **1시간 동안** 다시 송출할 수 없습니다.

![입력 비트레이트 상한 초과 제한 화면(영어)](https://cdn.krnk.org/kuronekoserver/nyst/warning/bitrate-en.png)

**해결 방법**

1. 동시에 송출 중인 모든 인코더의 영상·음성 비트레이트를 합산합니다.
2. 각 송출의 비트레이트를 낮추거나 필요 없는 동시 송출을 종료해 조직 합계를 상한 이내로 맞춥니다.
3. 대시보드에서 정지 대상 키의 해제 예정 시각을 확인합니다.
4. 제한 해제 후 다시 연결합니다. 더 높은 상한이 필요하면 요금제 변경 또는 추가 비트레이트를 신청합니다.

### 기타 이용약관 위반

관리자가 이용약관 위반을 확인하면 대상 조직 또는 사용자의 송출을 정지하고 차단합니다. 이 제한에는 자동 해제 시각이 없습니다.

![이용약관 위반 제한 화면(영어)](https://cdn.krnk.org/kuronekoserver/nyst/warning/tos-en.png)

**해결 방법**

1. [Nyan Streaming 이용약관](https://krnk.org/terms/nyan-streaming)과 알림에 표시된 조항을 확인합니다.
2. 해당 콘텐츠를 중지하거나 수정합니다.
3. 차단 검토 또는 해제를 요청하려면 [문의](https://krnk.org/contact/)해 주세요.

## 기타 상한

### 동시 시청자 수

조직 전체의 동시 시청자 수가 요금제 상한에 도달하면 새로운 시청자 연결이 거부됩니다. 이미 시청 중인 연결은 유지됩니다. 자리를 확보하거나 요금제 / 시청자 애드온을 변경하세요.

### 스토리지 용량

조직의 스토리지 상한에 도달하면 녹화가 자동으로 중지됩니다. 송출 자체는 계속되며 중지 시점까지의 영상은 업로드됩니다. 불필요한 아카이브·미디어를 삭제하거나 용량을 추가하세요.

### 지역 제한

일본 국내로 제한된 노드·요금제는 허용 지역 밖에서 시청할 수 없습니다. 스트림 키의 요금제, 선택한 노드, 리전을 확인하세요.

## 문의 시 함께 전달할 정보

- 조직명과 스트림 키의 **표시 이름**(송출용 시크릿은 보내지 마세요)
- 발생 시각과 시간대
- 사용한 노드 / 리전과 프로토콜(RTMP / RTSP / HLS / WebRTC)
- 대시보드에 표시된 오류 또는 제한 사유
- OBS 통계나 로그를 첨부하는 경우 송출용 시크릿과 개인정보를 먼저 삭제한 자료
