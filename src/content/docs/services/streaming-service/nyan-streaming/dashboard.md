Nyan Streaming のストリームキー、録画、分析、通知、チーム設定は [Web ダッシュボード](https://dash.nyst.live/) から管理します。

:::note
設定と利用状況は**組織（チーム）単位**です。ログイン後、画面左上で操作対象のチームを選択してください。
:::

![Nyan Streaming ダッシュボードの概要画面](/images/nyan-streaming/dashboard/overview.png)

トップ画面では、現在の配信数、総視聴者数、アクティブなストリームキー、録画ストレージ使用量、配信サーバーの稼働状況、最近のアクティビティを確認できます。

## 目的別ガイド

| やりたいこと                           | ページ                                         |
| -------------------------------------- | ---------------------------------------------- |
| 配信キーと配信・視聴 URL を管理する    | [ストリームキー](./stream-keys/)               |
| クラウド録画を探して保存する           | [アーカイブ](./archives/)                      |
| CDN で配信するファイルを管理する       | [メディア](./media/)                           |
| 視聴者数と配信品質を確認する           | [分析](./analytics/)                           |
| 認証・設定変更などの操作履歴を調べる   | [アクティビティ](./activity/)                  |
| 配信ノードのオンライン状況を確認する   | [サーバー稼働状況](./servers/)                 |
| JASRAC / NexTone 管理楽曲を報告する    | [楽曲利用申請](./music-reports/)               |
| メンバーの招待と権限を管理する         | [ユーザー](./users/)                           |
| 組織・請求・通知・セキュリティを変える | [設定](./settings/)                            |

## 左サイドバー

| メニュー                  | 主な用途                                     |
| ------------------------- | -------------------------------------------- |
| **ダッシュボード**        | 組織全体の配信・視聴・ストレージ概況         |
| **ストリームキー**        | 配信認証情報、接続 URL、番組送出の管理       |
| **アーカイブ**            | 録画の検索、再生、共有、ダウンロード、削除   |
| **メディア**              | CDN 用ファイルのアップロードと管理           |
| **分析**                  | リアルタイム統計、時系列統計、認証ログ       |
| **アクティビティ**        | 組織内の操作履歴と監査                       |
| **サーバー稼働状況**      | リージョン・ノード別のオンライン状況         |
| **楽曲利用申請**          | JASRAC / NexTone 管理楽曲の利用報告          |
| **ユーザー**              | チームメンバーと権限の管理                   |
| **設定**                  | 組織情報、請求、通知、セキュリティ、API キー |

:::tip
掲載画像は 2026 年 8 月 21 日時点の日本語 UI です。アカウント情報やストリームシークレットが写らない範囲だけを掲載しています。
:::
