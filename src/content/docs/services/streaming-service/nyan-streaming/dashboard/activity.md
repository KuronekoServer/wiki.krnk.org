**アクティビティ**は、組織内のユーザー操作とシステムイベントを追跡する監査画面です。

![Nyan Streaming のアクティビティ画面](/images/nyan-streaming/dashboard/activity.png)

## 集計カード

過去24時間の総アクティビティ、認証失敗、ストリームキーの作成・削除、チームの招待・削除を確認できます。普段と異なる増加がある場合は、下のログで実行者と時刻を確認します。

## 記録される主なイベント

- ログイン成功・失敗、ログアウト、ユーザー登録
- ストリームキーの作成、更新、削除、再生成
- 録画の削除、再配信先の追加・削除
- APIキーの作成・失効、通知テスト
- プランのアップグレード・ダウングレード
- メンバーの招待・削除・ロール変更、設定変更

## ログを調べる

検索欄でイベントやユーザーを絞り込みます。各行にはイベント、実行者、日時、取得できた場合のIPアドレスが表示され、操作メニューから詳細を開いたりレビュー済みにしたりできます。

**すべてエクスポート**または選択行の**エクスポート**で調査用に保存できます。削除権限がある場合は複数行を選んで削除できます。

:::caution
監査ログを削除すると調査に使えなくなります。通常はエクスポートして保管してから削除してください。
:::

## 不審な操作を見つけた場合

1. イベントの実行者、日時、IPアドレス、対象を記録します。
2. [分析](../analytics/)の認証ログと時刻を照合します。
3. キー漏えいが疑われる場合は[ストリームキー](../stream-keys/)を再生成します。
4. 不要なセッションやメンバーを[設定](../settings/)と[ユーザー](../users/)で見直します。
