**分析**では、組織内で配信中のストリームをリアルタイム値と時系列データから確認できます。

![Nyan Streaming の分析画面](/images/nyan-streaming/dashboard/analytics.png)

## 4つのタブ

| タブ               | 確認できる内容                                                                   |
| ------------------ | -------------------------------------------------------------------------------- |
| **視聴者**         | アクティブ配信数、同時視聴者数、合計インジェストビットレート、リアルタイムグラフ |
| **時間別**         | 期間を指定した視聴者数・配信量の時系列統計                                       |
| **パフォーマンス** | 平均インジェスト / エグレス、キー別ランキング、視聴プロトコル構成                |
| **認証ログ**       | 最近の配信認証の成功・失敗、ユーザー、IPアドレス、日時                           |

## 視聴者とストリームの健全性

ライブグラフは数秒ごとにコントロールプレーンから取得した組織全体の値です。**ストリームの健全性**では、キーごとの同時視聴者数、インジェスト / エグレスビットレート、使用中の視聴プロトコルを比較できます。

インジェストは配信者からサーバーへ入る通信、エグレスはサーバーから視聴者へ出る通信です。インジェストだけが0の場合は配信元、エグレスだけが増えない場合は視聴 URL や認証設定を確認してください。

## パフォーマンス

キーごとのインジェストビットレート順位、HLS・WHEP・RTSPなどの接続構成、ストリームあたりの平均値、最終更新時刻を確認できます。配信設定を変えた前後や、視聴方式を切り替えた前後の比較に使います。

## 認証ログ

書き込み（配信）認証の結果を監視します。失敗が続く場合は、ストリームキー、取り込み用シークレット、配信 URL、接続元 IP 制限を確認してください。シークレットそのものはログに表示されません。

:::note
配信がないときはライブ値やランキングが空になります。APIへ接続できないエラーが表示された場合は、再読み込み後も続くか確認してから[トラブルシューティング](../../troubleshooting/)へ進んでください。
:::
