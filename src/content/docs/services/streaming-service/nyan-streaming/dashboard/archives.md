**アーカイブ**には、ストリームキーで録画した過去の配信が組織単位で表示されます。

![Nyan Streaming のアーカイブ画面](/images/nyan-streaming/dashboard/archives.png)

## 録画に対応しているノード

:::caution
**録画機能を利用できるのはNode02のみ**です。Node01とNode03では録画を利用できません。

- **Node01**：JASRAC・NexToneとの許諾契約上、録画データを利用者へ提供できないためです。
- **Node03**：長時間配信向けのノードであり、録画によるサーバー保存容量の圧迫を避けるためです。

録画が必要な配信ではNode02を選択してください。Node02を使用する場合でも、契約プランで録画機能が提供されている必要があります。
:::

## 録画を作成する

1. **ストリームキー**から対象のキーを開きます。
2. **録画**タブで自動録画を有効にします。
3. 配信を開始します。
4. 配信終了後、処理が完了するとアーカイブに表示されます。

録画機能、組織全体の保存容量、保持期間はプランによって異なります。[プラン・制限](../../plans-and-limits/)と[ノードの選び方](../servers/#ノードの選び方)も確認してください。

## 画面上部の集計

| 項目               | 意味                                   |
| ------------------ | -------------------------------------- |
| **総アーカイブ数** | 録画されたセッションの件数             |
| **総時間**         | すべての録画時間の合計                 |
| **総視聴者数**     | 各セッションの平均視聴者数を累積した値 |
| **平均時間**       | 1 セッションあたりの平均録画時間       |

期間は**すべて / 過去7日間 / 過去30日間 / 過去90日間**から選べます。検索欄ではタイトルを絞り込めます。

## 録画の操作

各行の操作メニューから、別タブでの視聴、ダウンロード、直リンクのコピー、名前変更、削除を実行できます。複数行を選択すると一括ダウンロードまたは一括削除ができ、**すべてエクスポート**では一覧全体を書き出せます。

名前変更は一覧・視聴ページの表示名とダウンロード時のファイル名に反映されますが、直リンク URL は変わりません。

:::caution
削除した録画は元に戻せません。必要な録画は先にダウンロードし、対象のタイトルと開始時刻を確認してから削除してください。
:::

## 表示されない場合

- 録画を有効にしたストリームキーで配信したか確認します。
- 配信先としてNode02を使用したか確認します。Node01とNode03の配信は録画されません。
- 配信直後は状態が**処理中**または**保留中**になるため、完了まで待ちます。
- 組織ストレージが上限に達していないか、[メディア](../media/)で確認します。
- 画面左上で正しいチームを選択しているか確認します。
