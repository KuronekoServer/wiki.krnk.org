**メディア**では、動画・画像・その他のファイルをアップロードし、CDN 経由で配信できます。録画と手動アップロードは同じ組織ストレージを使用します。

![Nyan Streaming のメディア画面](/images/nyan-streaming/dashboard/media.png)

## 組織ストレージ

画面上部には、使用量と上限、残り容量、使用率、録画とメディアそれぞれの内訳が表示されます。上限なしのプランでは現在の使用量だけが表示されます。

ストレージ上限に達すると、新しい録画やアップロードが失敗します。不要なファイルを削除するか、必要なファイルをダウンロードしてから整理してください。

## ファイルをアップロードする

1. アップロード枠をクリックするか、ファイルをドラッグ＆ドロップします。
2. 進捗が 100% になり、状態が**準備完了**になるまで待ちます。
3. 一覧で名前、種類、サイズ、状態を確認します。

1 ファイルの上限は **1 GB** です。動画は処理中にすぐ再生できない場合があります。**失敗**と表示された場合は、容量と通信状態を確認して再度アップロードします。

## アップロード後の操作

- 動画は再生ボタンで内容を確認できます。
- 名前変更では拡張子を保ったままベース名だけを変更します。
- 使用できる文字は英字、数字、ハイフン（`-`）、アンダースコア（`_`）です。空白、日本語、その他の記号は使えません。
- 不要なファイルは削除できます。

:::caution
メディアの名前を変更するとファイル URL も変わり、以前の URL は無効になります。Webサイト、告知、プレイヤーなどで共有済みのリンクも更新してください。
:::

:::caution
削除は取り消せません。利用中の URL がないことを確認してから削除してください。
:::
