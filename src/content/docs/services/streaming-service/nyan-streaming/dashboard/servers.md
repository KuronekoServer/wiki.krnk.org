**サーバー稼働状況**では、配信ノードから送られるハートビートをもとに、リージョン別のオンライン状況を確認できます。

![Nyan Streaming のサーバー稼働状況画面](/images/nyan-streaming/dashboard/servers.png)

## 表示の見方

画面上部には稼働中ノード数、登録ノード総数、リージョン数、最終更新時刻が表示されます。各リージョンのカードではノードごとに**オンライン**または**オフライン**を確認できます。運用上の都合でホスト名を非公開にしているリージョンは、台数だけが表示されます。

**更新**を押すと最新の状態を再取得します。APIへ接続できない場合や登録サーバーがない場合は、画面にその状態が表示されます。

## 配信前・障害時の確認

1. 配信に使うリージョンがオンラインか確認します。
2. オフラインの場合は再読み込みし、[KuronekoServer Status](https://status.krnk.org/)も確認します。
3. 利用可能な別リージョンがある場合は、そのリージョンの配信 URL をOBSなどへ設定します。
4. 配信開始後は[分析](../analytics/)でインジェストが届いているか確認します。

:::note
ダッシュボード上で表示・選択したノードだけで接続先が固定されるわけではありません。実際の接続先は、配信ソフトへ入力した URL で決まります。
:::
