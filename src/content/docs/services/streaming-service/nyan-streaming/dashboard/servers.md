**サーバー稼働状況**では、配信ノードから送られるハートビートをもとに、リージョン別のオンライン状況を確認できます。

![Nyan Streaming のサーバー稼働状況画面](/images/nyan-streaming/dashboard/servers.png)

## 表示の見方

画面上部には稼働中ノード数、登録ノード総数、リージョン数、最終更新時刻が表示されます。各リージョンのカードではノードごとに**オンライン**または**オフライン**を確認できます。運用上の都合でホスト名を非公開にしているリージョンは、台数だけが表示されます。

**更新**を押すと最新の状態を再取得します。APIへ接続できない場合や登録サーバーがない場合は、画面にその状態が表示されます。

## ノードの選び方

配信内容と運用時間に合わせて、次のノードを選択してください。

| ノード     | 主な用途                       | 特徴と注意点                                                                                                                                         |
| ---------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Node01** | JASRAC・NexTone管理楽曲の配信 | 管理楽曲を使用する配信向けの日本国内限定ノードです。使用した楽曲はダッシュボードから、**利用した月の末日まで**に必ず報告してください。録画は利用できません。 |
| **Node02** | 通常の配信・グローバル配信     | 世界各地の配信サーバーを利用し、幅広い国・地域へ安定して届けるための標準ノードです。イベントを含む通常の配信と、録画が必要な配信ではNode02を選択します。       |
| **Node03** | 低ビットレートの長時間配信     | 低ビットレートで長時間・長期間の継続配信を行うためのノードです。24時間連続配信の制限対象外で、24時間を超える配信にも利用できます。録画は利用できません。       |

:::caution
Node01で利用した管理楽曲の報告がない場合や、報告内容に不備がある場合は、アカウントへのペナルティや追加利用料の対象になることがあります。詳しい手順は[楽曲利用申請](../music-reports/)を確認してください。
:::

:::note
Node03でも、プランごとのビットレート上限、ストレージ上限、利用規約など、24時間制限以外の条件は引き続き適用されます。
:::

:::caution[録画機能]
録画に対応しているのはNode02のみです。Node01はJASRAC・NexToneとの許諾契約上、録画データを利用者へ提供できません。Node03は長時間配信向けのため、録画によるサーバー保存容量の圧迫を避ける目的で録画に対応していません。詳しくは[アーカイブ](../archives/)を確認してください。
:::

## 配信前・障害時の確認

1. 配信に使うリージョンがオンラインか確認します。
2. オフラインの場合は再読み込みし、[KuronekoServer Status](https://status.krnk.org/)も確認します。
3. 利用可能な別リージョンがある場合は、そのリージョンの配信 URL をOBSなどへ設定します。
4. 配信開始後は[分析](../analytics/)でインジェストが届いているか確認します。

:::note
ダッシュボード上で表示・選択したノードだけで接続先が固定されるわけではありません。実際の接続先は、配信ソフトへ入力した URL で決まります。
:::
