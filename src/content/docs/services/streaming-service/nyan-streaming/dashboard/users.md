**ユーザー**では、組織に参加しているメンバー、権限、招待状況、最終アクティブ時刻を管理します。

## 画面の見方

画面上部には総メンバー数、管理者数、保留中の招待数が表示されます。**全メンバー**では名前やメールアドレスを検索し、ロール、状態、最終アクティブ時刻を確認できます。

:::note
このページのスクリーンショットは、メンバーの氏名やメールアドレスを公開しないため掲載していません。画面構成と操作は以下で説明します。
:::

## ロール

| ロール           | 権限の目安                                     |
| ---------------- | ---------------------------------------------- |
| **オーナー**     | 請求、所有権移譲、組織削除を含む完全なアクセス |
| **サブオーナー** | 所有権移譲と組織削除を除く、ほぼすべての操作   |
| **メンバー**     | ストリームキーと分析への読み取り専用アクセス   |

必要最小限のロールを割り当ててください。配信設定や通知を変更する担当者だけを管理者にします。

## メンバーを招待する

1. **メンバーを招待**を押します。
2. 招待先のメールアドレスとロールを指定します。
3. 送信後、状態が**招待済み**になったことを確認します。
4. 相手が参加すると**アクティブ**へ変わります。

保留中の招待は操作メニューから再送または取り消しができます。

## ロール変更と削除

各メンバーの操作メニューからロールを変更できます。メンバーを削除すると、そのユーザーは組織のストリームキー、録画、分析、設定へアクセスできなくなります。

:::caution
担当変更や退職時は、メンバー削除だけでなく、共有していたストリームキーやAPIキーの再生成・失効も検討してください。最後のオーナーを削除しないでください。
:::
