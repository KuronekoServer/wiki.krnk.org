# Artifacter 配装卡生成 API
## 概述
此 API 使用 Enka.Network API 数据，生成 Artifacter 风格的图像。

通过 GET 请求访问，即可生成各种配装卡图像。


# API 规范

https://artifacter-imagegen-api.krnk.org/docs

服务页面: https://artifacter-imagegen-api.krnk.org

:::danger
每秒发送 10 次或更多请求时，会返回「429 Too many Requests」。
如需提高 API 请求速率限制，请[联系我们](https://discord.krnk.org)。
:::
