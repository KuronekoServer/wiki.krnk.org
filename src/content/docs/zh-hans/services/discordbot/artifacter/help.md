# /help
## 概述
可查看命令说明，以及更改或删除自己的 UID。

:::note
命令说明等内容与[关于 Artifacter](/zh-hans/services/discordbot/artifacter/)页面相同。
:::

## 使用方法
```
/help
```

## 工作流程
```mermaid
graph LR
    A{/help}
    A --> B[关于 Artifacter]
    A --> C[更改和删除 uid]
    C --> D[uid 登记和删除表单]
```
