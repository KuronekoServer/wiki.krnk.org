# 连接命令
## 概述
这些基本命令用于让语音朗读 BOT 加入或离开语音频道，以及跳过朗读队列。

## 命令列表
命令名称 | 概述 | 主要参数
-- | -- | --
/join | 加入语音频道。 | 语音频道、强制
/disconnect | 断开语音频道连接。 | 无
/skip | 跳过当前朗读并清空队列。 | 无

## /join
连接语音频道。
省略语音频道参数时，会连接到命令执行者当前所在的语音频道。

```text
/join
/join ボイスチャンネル:#雑談VC
/join ボイスチャンネル:#雑談VC 強制:true
```

补充说明:
- 无法加入执行者无权连接的语音频道。
- 如果已经连接同一个语音频道，会将执行命令的文字频道添加为新的朗读对象。
- 如果 BOT 正在其他语音频道使用且未指定强制参数，会显示移动确认。

## /disconnect
断开当前连接的语音频道。

```text
/disconnect
```

补充说明:
- 仅在 BOT 已连接时可用。
- 拥有 BOT 所在语音频道操作权限的用户可执行此命令。

## /skip
跳过当前正在朗读的内容，并清空待处理队列。

```text
/skip
```

补充说明:
- 仅在 BOT 已连接时可用。
- 拥有 BOT 所在语音频道操作权限的用户可执行此命令。
