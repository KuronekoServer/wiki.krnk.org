# 实用命令
## 概述
这些命令用于查看 BOT 帮助、检查响应及获取邀请链接。

## 命令列表
命令名称 | 概述 | 补充说明
-- | -- | --
/help | 显示 BOT 说明和命令列表。 | 部分环境还会在尚未订阅时显示订阅指引。
/ping | 检查 BOT 的响应速度。 | 以毫秒显示大致响应时间。
/exvoice | 显示可用 ExVoice 列表的 URL。 | 回复仅对你可见。
/invite | 显示邀请链接。 | 回复仅对你可见。

## /help
显示 BOT 概述及可用斜杠命令的列表。

```text
/help
```

## /ping
检查 BOT 的响应速度。

```text
/ping
```

## /dashboard
显示服务器控制面板的 URL。

```text
/dashboard
```

## /exvoice
显示可用 ExVoice 列表的 URL。

```text
/exvoice
```

## /invite
显示 BOT 的邀请链接。

```text
/invite
```
