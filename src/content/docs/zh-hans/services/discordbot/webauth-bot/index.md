# Web 验证 BOT
## 关于 Web 验证 BOT
Web 验证 BOT 是使用 hCaptcha 的验证 BOT。

## 命令列表与使用指南
命令名称 | 概述 |
-- | -- |
/webauth | 指定用于验证的身份组，并放置验证面板。
/check | 查看当前为验证设置的身份组。

## 常见问题
> 完成验证后未获得身份组，或者发生了错误。

:::caution
请确认 Web 验证 BOT 的身份组位于要授予的身份组之上。
如果设置正确，请[联系我们](https://discord.krnk.org)。
:::

![image](https://cdn.krnk.org/kuronekoserver/wiki/webauth-bot/role.webp)

> 显示「应用程序未响应」或「交互失败」，或者没有收到回复

BOT 可能正在维护或发生了错误。请先查看[支持服务器](https://discord.krnk.org)的 #📢service-アナウンス 频道确认维护状态，再通过 #お問い合わせ 频道告知我们。
