Nyan Streaming 的推流密钥、录制、分析、通知和团队设置可从 [Web 控制台](https://dash.nyst.live/)管理。

:::note
设置和使用情况按**组织（团队）**管理。登录后，请在左上角选择要操作的团队。
:::

![Nyan Streaming 控制台概览页面](/images/nyan-streaming/dashboard/overview.png)

首页可查看当前直播数、总观众人数、活跃推流密钥、录制存储使用量、直播服务器运行状态和最近活动。

## 按目的查找指南

| 要进行的操作 | 页面 |
| --- | --- |
| 管理推流密钥及推流／观看 URL | [推流密钥](./stream-keys/) |
| 查找和保存云端录制 | [存档](./archives/) |
| 管理通过 CDN 分发的文件 | [媒体](./media/) |
| 查看观众人数和直播质量 | [分析](./analytics/) |
| 查询身份验证、设置变更等操作历史 | [活动](./activity/) |
| 查看直播节点的在线状态 | [服务器运行状态](./servers/) |
| 报告 JASRAC / NexTone 管理音乐作品的使用 | [音乐使用申请](./music-reports/) |
| 管理成员邀请和权限 | [用户](./users/) |
| 更改组织、账单、通知和安全设置 | [设置](./settings/) |

## 左侧边栏

| 菜单 | 主要用途 |
| --- | --- |
| **控制台** | 整个组织的直播、观看和存储概况 |
| **推流密钥** | 管理推流凭据、连接 URL 和节目播出 |
| **存档** | 搜索、播放、分享、下载和删除录制 |
| **媒体** | 上传和管理 CDN 文件 |
| **分析** | 实时统计、时间序列统计和身份验证日志 |
| **活动** | 组织内操作历史与审计 |
| **服务器运行状态** | 各区域与节点的在线状态 |
| **音乐使用申请** | 报告 JASRAC / NexTone 管理音乐作品的使用 |
| **用户** | 管理团队成员和权限 |
| **设置** | 组织信息、账单、通知、安全和 API 密钥 |

:::tip
所示图片为 2026 年 8 月 21 日的日语 UI。仅展示未包含账户信息或推流机密值的区域。
:::
