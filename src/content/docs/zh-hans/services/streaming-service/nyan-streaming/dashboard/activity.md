**活动**是用于追踪组织内用户操作和系统事件的审计页面。

![Nyan Streaming 活动页面](/images/nyan-streaming/dashboard/activity.png)

## 统计卡片

可查看过去 24 小时的总活动数、身份验证失败次数、推流密钥创建／删除以及团队邀请／删除情况。如出现异常增长，请在下方日志中检查执行者和时间。

## 主要记录事件

- 登录成功／失败、退出登录、用户注册
- 创建、更新、删除和重新生成推流密钥
- 删除录制、添加／删除转推目标
- 创建／撤销 API 密钥、通知测试
- 套餐升级／降级
- 成员邀请／删除／角色变更、设置变更

## 查询日志

通过搜索栏筛选事件或用户。每行显示事件、执行者、日期时间以及能够获取时的 IP 地址，可通过操作菜单打开详情或标记为已审核。

可使用**全部导出**或选中行的**导出**保存调查资料。如具备删除权限，也可选择多行删除。

:::caution
删除审计日志后，将无法再用于调查。通常应先导出保存后再删除。
:::

## 发现可疑操作时

1. 记录事件执行者、日期时间、IP 地址和目标。
2. 与[分析](../analytics/)中的身份验证日志核对时间。
3. 如怀疑密钥泄露，请重新生成[推流密钥](../stream-keys/)。
4. 在[设置](../settings/)和[用户](../users/)中检查不需要的会话或成员。
