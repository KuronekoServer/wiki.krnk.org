**分析**可通过实时数值和时间序列数据查看组织内正在直播的流。

![Nyan Streaming 分析页面](/images/nyan-streaming/dashboard/analytics.png)

## 四个选项卡

| 选项卡 | 可查看的内容 |
| --- | --- |
| **观众** | 活跃直播数、同时观看人数、总输入码率和实时图表 |
| **按时间** | 指定期间内观众人数和直播量的时间序列统计 |
| **性能** | 平均输入／输出、按密钥排名及观看协议构成 |
| **身份验证日志** | 最近推流身份验证的成功／失败、用户、IP 地址和日期时间 |

## 观众与流健康状态

实时图表为每隔数秒从控制平面获取的整个组织的数据。在**流健康状态**中，可比较各密钥的同时观看人数、输入／输出码率和使用中的观看协议。

输入指主播到服务器的通信，输出指服务器到观众的通信。只有输入为 0 时，请检查推流来源；只有输出不增长时，请检查观看 URL 或身份验证设置。

## 性能

可查看各密钥的输入码率排名、HLS / WHEP / RTSP 等连接构成、每个流的平均值和最后更新时间。可用于比较更改推流设置或切换观看方式前后的情况。

## 身份验证日志

用于监控写入（推流）身份验证结果。如持续失败，请检查推流密钥、接入机密值、推流 URL 和来源 IP 限制。日志不会显示机密值本身。

:::note
没有直播时，实时数值和排名会为空。如显示无法连接 API 的错误，请先检查重新加载后问题是否仍然存在，再参阅[故障排除](../../troubleshooting/)。
:::
