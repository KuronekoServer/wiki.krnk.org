**存档**按组织显示通过推流密钥录制的历史直播。

![Nyan Streaming 存档页面](/images/nyan-streaming/dashboard/archives.png)

## 支持录制的节点

:::caution
**只有 Node02 可以使用录制功能。**Node01 和 Node03 无法录制。

- **Node01**：根据与 JASRAC、NexTone 的授权协议，无法向用户提供录制数据。
- **Node03**：该节点面向长时间直播，为避免录制挤占服务器存储容量，不支持录制。

需要录制时，请选择 Node02。即使使用 Node02，订阅套餐也必须提供录制功能。
:::

## 创建录制

1. 从**推流密钥**打开目标密钥。
2. 在**录制**选项卡中启用自动录制。
3. 开始推流。
4. 直播结束并处理完成后，录制会显示在存档中。

录制功能、整个组织的存储容量和保留期限取决于套餐。请同时查看[套餐与限制](../../plans-and-limits/)和[如何选择节点](../../nodes/)。

## 页面顶部统计

| 项目 | 含义 |
| --- | --- |
| **总存档数** | 已录制的会话数量 |
| **总时长** | 所有录制时长的合计 |
| **总观众人数** | 各会话平均观众人数的累计值 |
| **平均时长** | 每个会话的平均录制时长 |

期间可选择**全部／过去 7 天／过去 30 天／过去 90 天**。搜索栏可按标题筛选。

## 录制操作

每行的操作菜单可用于在新选项卡观看、下载、复制直链、重命名和删除。选择多行后可批量下载或批量删除，**全部导出**可导出整个列表。

重命名会更改列表和观看页面的显示名称，以及下载时的文件名，但不会改变直链 URL。

:::caution
删除的录制无法恢复。请先下载需要的录制，并确认目标标题和开始时间后再删除。
:::

## 未显示录制时

- 确认是否使用启用了录制的推流密钥进行直播。
- 确认推流目标是否为 Node02。Node01 和 Node03 的直播不会录制。
- 直播刚结束时状态可能为**处理中**或**待处理**，请等待完成。
- 在[媒体](../media/)中检查组织存储是否已达上限。
- 确认左上角选择了正确的团队。
