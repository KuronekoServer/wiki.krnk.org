:::note
**Nyan Streaming Japan 不支持直播录制和文件上传功能。** 本页面关于录制和媒体的说明适用于支持这些功能的 Nyan Streaming 服务。
:::


**媒体**可用于上传视频、图片及其他文件，并通过 CDN 分发。录制和手动上传使用同一份组织存储。

![Nyan Streaming 媒体页面](/images/nyan-streaming/dashboard/media.png)

## 组织存储

页面顶部显示使用量与上限、剩余容量、使用率，以及录制和媒体各自的明细。没有容量上限的套餐仅显示当前使用量。

达到存储上限后，新的录制或上传会失败。请删除不需要的文件，或先下载所需文件再整理。

## 上传文件

1. 点击上传区域，或拖放文件。
2. 等待进度达到 100%，且状态变为**就绪**。
3. 在列表中确认名称、类型、大小和状态。

单个文件上限为 **10 GB**。视频处理期间可能无法立即播放。如显示**失败**，请检查容量和网络状态后重新上传。

## 上传后的操作

- 视频可通过播放按钮检查内容。
- 重命名时保留扩展名，仅更改基本文件名。
- 允许使用英文字母、数字、连字符（`-`）和下划线（`_`）。不允许使用空格、日文或其他符号。
- 可删除不需要的文件。

:::caution
重命名媒体后，文件 URL 也会变化，旧 URL 将失效。请同时更新网站、公告和播放器等处已分享的链接。
:::

:::caution
删除无法撤销。请确认没有正在使用的 URL 后再删除。
:::
