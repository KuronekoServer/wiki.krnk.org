**服务器运行状态**根据直播节点发送的心跳，显示各区域的在线状态。

![Nyan Streaming 服务器运行状态页面](/images/nyan-streaming/dashboard/servers.png)

## 如何查看

页面顶部显示运行中的节点数、已登记的节点总数、区域数和最后更新时间。各区域卡片中可查看每个节点的**在线**或**离线**状态。因运营原因未公开主机名的区域仅显示台数。

点击**刷新**可重新获取最新状态。无法连接 API 或没有已登记服务器时，页面会显示相应状态。

## 如何选择节点

服务和连接地址请参阅[选择服务和节点](../../nodes/)。

## 推流前或故障时的检查

1. 确认要用于推流的区域是否在线。
2. 如离线，请重新加载，并查看 [KuronekoServer Status](https://status.krnk.org/)。
3. 如有其他可用区域，将该区域的推流 URL 设置到 OBS 等软件。
4. 开始推流后，在[分析](../analytics/)中确认是否收到输入。

:::note
仅在控制台中显示或选择节点，并不会固定连接目标。实际连接目标由输入直播软件的 URL 决定。
:::
