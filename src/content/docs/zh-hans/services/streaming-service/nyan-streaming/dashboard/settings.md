**设置**用于管理整个组织的基本信息、付款、通知、访问控制和公开 API 密钥。可更改的项目取决于当前角色。

![Nyan Streaming 设置中的安全选项卡](/images/nyan-streaming/dashboard/settings.png)

:::note
图片展示安全选项卡，包含各卡片的底部。团队 ID、账单信息、账户删除等敏感区域未包含在公开图片中。
:::

## 常规

设置团队名称、团队 URL、头像和**默认语言**。默认语言用于直播限制的邮件、Webhook、控制台通知以及观看页面的警告视频。

同一页面也提供团队 ID、所有权转移、退出团队和删除团队操作。除外部集成需要团队 ID 的情况外，请勿公开。

## 账单

查看当前套餐、付款方式和账单历史。更改为付费套餐前，需要有效的付款方式。添加、更新和删除付款方式应由所有者等具备必要权限的用户执行。

:::caution
账单页面可能显示付款信息。共享屏幕或截图前请确认内容。
:::

## 通知

### 通知目标

可选择应用内、邮件和 Webhook 通知。保存 Webhook URL 后，可发送普通格式或 Discord embed 格式的测试通知。

### 通知事件

- 直播开始／结束
- 身份验证失败
- 观众人数里程碑
- 每周报告
- 超过码率上限
- 连续直播超过 24 小时
- 达到存储上限

向正式使用的 Webhook 发送测试时，会实际发送通知。请先告知通知接收方的运维人员再执行。

## 安全

- 启用或禁用双因素身份验证。
- 选择会话超时时长。
- 按 `IP / CIDR` 允许或拒绝推流来源 IP。
- 查看 API 密钥管理页面的链接及 API 速率限制。

IP 规则按从上到下的顺序评估，应用首个匹配规则。默认行为为允许。

:::note
IP 限制仅适用于推流（publish）。不提供针对公开观看的 IP 限制。
:::

## API 密钥

可指定密钥名称和可选的有效期，创建公开 API 密钥。列表中可查看创建日期、最后使用日期和有效期，并撤销不需要的密钥。

:::caution
密钥本体仅在创建后显示一次。请保存到安全的位置，勿粘贴到聊天或公开仓库中。泄露时请立即撤销并重新创建。
:::

API 页面也显示身份验证请求头和端点说明。详情请参阅[公开 API](../../api/)。

## 所有权转移、退出与删除

这些操作影响范围较大。请确认目标团队、接收方、当前角色和账单状态，并保存必要的推流密钥、录制和审计日志后再执行。
