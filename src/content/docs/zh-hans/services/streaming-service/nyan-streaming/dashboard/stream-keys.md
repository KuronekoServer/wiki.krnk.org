**推流密钥**用于创建、轮换和删除推流凭据，以及查看可提供给观众的 URL。

![推流密钥列表与节目播出](/images/nyan-streaming/dashboard/stream-keys.png)

## 创建密钥

1. 打开左侧菜单的**推流密钥**。
2. 选择**新建密钥**，指定名称和套餐。
3. 按需设置观看密钥、节点、区域和备注。
4. 打开已创建的密钥，确认推流 URL 和观看 URL。

观看密钥留空时会随机生成。如需自定义值，请使用英文字母、数字、连字符（`-`）和下划线（`_`）。接入机密值始终随机生成。

不确定节点用途时，请参阅[如何选择节点](../../nodes/)。没有特殊要求时，请选择标准 Node02。

:::caution
接入用推流密钥等同于密码。不要让其出现在截图或直播画面中，也不要与第三方分享。泄露时请**重新生成密钥**，立即使旧值失效。
:::

## 推流与观看地址

密钥的**概览**中可查看所选节点对应的以下信息。

| 用途 | 显示内容 |
| --- | --- |
| 推流 | RTMP、WebRTC（WHIP）、RTSP 接入 URL 和接入路径 |
| 观看 | RTSP、RTSPT（TCP）、WebRTC（WHEP）、HLS、RTMP 观看 URL |
| 限制 | 组织合计的码率与观众上限、录制与转推、存储及地区限制 |

在页面上选择节点并不会固定推流目标。实际连接目标由输入 OBS 或播放器的 URL 决定。

## 密钥详情选项卡

| 选项卡 | 内容 |
| --- | --- |
| **概览** | 推流／观看 URL、套餐、上限和可用功能 |
| **浏览器推流** | 通过 WebRTC（WHIP）直播摄像头、麦克风或屏幕 |
| **浏览器观看** | 通过 WebRTC（WHEP）低延迟观看 |
| **HLS 观看** | 在控制台内检查 `.m3u8` |
| **统计** | 整个密钥和各节点的实时统计 |
| **录制** | 启用 Node02 自动录制，以及此密钥的录制列表 |
| **转推** | 管理 YouTube、Twitch 等外部 RTMP 目标 |
| **均衡器** | EQ 与混响设置 |

EQ 提供 Flat / Voice / Music / Bass Boost / Treble Boost 预设，混响提供 Studio / Room / Hall / Cathedral 预设。更改会在约 3 秒内反映到观看端。

:::note
只有 Node02 可以使用录制功能。Node01、Node03 不支持录制的原因及使用条件，请参阅[存档](../archives/#支持录制的节点)。
:::

## 节目播出（频道）

Pro 及以上套餐可切换通过组织共用观看 URL 播出的推流密钥。这是一个保持观众连接、仅替换推流来源的直播切换器。

- 选择密钥，或选择**停止播出**。
- 切换在新密钥的下一个关键帧生效，最多会发生 1 GOP 时长的短暂中断。
- 切换前后请使用相同的分辨率、帧率、编解码器和音频设置。

## 密钥被暂停时

超过码率上限、连续直播 24 小时或违反服务条款时，列表会显示状态和预计解除时间。警告画面及恢复方法请参阅[故障排除](../../troubleshooting/)。
