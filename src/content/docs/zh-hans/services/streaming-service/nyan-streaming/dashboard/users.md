**用户**用于管理组织成员、权限、邀请状态和最后活跃时间。

## 如何查看页面

页面顶部显示总成员数、管理员数和待处理邀请数。在**全部成员**中，可通过姓名或邮件地址搜索，并查看角色、状态和最后活跃时间。

:::note
为避免公开成员姓名和邮件地址，本页未提供截图。以下说明页面结构和操作。
:::

## 角色

| 角色 | 权限范围参考 |
| --- | --- |
| **所有者** | 完整访问权限，包括账单、所有权转移和组织删除 |
| **共同所有者** | 除所有权转移和组织删除外的几乎所有操作 |
| **成员** | 对推流密钥和分析的只读访问 |

请分配满足需求的最低权限角色。仅将负责更改直播设置或通知的人员设为管理员。

## 邀请成员

1. 点击**邀请成员**。
2. 指定被邀请者的邮件地址和角色。
3. 发送后，确认状态变为**已邀请**。
4. 对方加入后，状态变为**活跃**。

待处理邀请可从操作菜单重新发送或取消。

## 更改角色和移除成员

可从各成员的操作菜单更改角色。移除成员后，该用户将无法访问组织的推流密钥、录制、分析和设置。

:::caution
人员交接或离职时，除移除成员外，还应考虑重新生成或撤销曾分享的推流密钥和 API 密钥。请勿移除最后一名所有者。
:::
