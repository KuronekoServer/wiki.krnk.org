# Artifacter 配裝卡生成 API
## 概述
此 API 使用 Enka.Network API 資料，生成 Artifacter 風格的圖片。

透過 GET 請求訪問，即可生成各種配裝卡圖片。


# API 規範

https://artifacter-imagegen-api.krnk.org/docs

服務頁面: https://artifacter-imagegen-api.krnk.org

:::danger
每秒發送 10 次或更多請求時，會返回「429 Too many Requests」。
如需提高 API 請求速率限制，請[聯繫我們](https://discord.krnk.org)。
:::
