# /help
## 概述
可查看命令說明，以及更改或刪除自己的 UID。

:::note
命令說明等內容與[關於 Artifacter](/zh-hant/services/discordbot/artifacter/)頁面相同。
:::

## 使用方法
```
/help
```

## 工作流程
```mermaid
graph LR
    A{/help}
    A --> B[關於 Artifacter]
    A --> C[更改和刪除 uid]
    C --> D[uid 登錄和刪除表單]
```
