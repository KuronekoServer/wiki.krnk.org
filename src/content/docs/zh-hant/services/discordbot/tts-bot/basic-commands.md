# 連線命令
## 概述
這些基本命令用於讓語音朗讀 BOT 加入或離開語音頻道，以及跳過朗讀佇列。

## 命令列表
命令名稱 | 概述 | 主要參數
-- | -- | --
/join | 加入語音頻道。 | 語音頻道、強制
/disconnect | 斷開語音頻道連線。 | 無
/skip | 跳過目前朗讀並清空佇列。 | 無

## /join
連線語音頻道。
省略語音頻道參數時，會連線到命令執行者目前所在的語音頻道。

```text
/join
/join ボイスチャンネル:#雑談VC
/join ボイスチャンネル:#雑談VC 強制:true
```

補充說明:
- 無法加入執行者無權連線的語音頻道。
- 如果已經連線同一個語音頻道，會將執行命令的文字頻道新增爲新的朗讀對象。
- 如果 BOT 正在其他語音頻道使用且未指定強制參數，會顯示移動確認。

## /disconnect
斷開目前連線的語音頻道。

```text
/disconnect
```

補充說明:
- 僅在 BOT 已連線時可用。
- 擁有 BOT 所在語音頻道操作權限的使用者可執行此命令。

## /skip
跳過目前正在朗讀的內容，並清空待處理佇列。

```text
/skip
```

補充說明:
- 僅在 BOT 已連線時可用。
- 擁有 BOT 所在語音頻道操作權限的使用者可執行此命令。
