# 付費方案說明
## 概述
付費方案可提高語音朗讀 BOT 的詞典字元數限制和朗讀字元數限制。
朗讀字元數等設定不會自動更新，請透過命令調整。
可在[這裏](https://payment.krnk.org)訂閱付費方案。
