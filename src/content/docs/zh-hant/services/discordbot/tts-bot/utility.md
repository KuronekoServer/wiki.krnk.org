# 實用命令
## 概述
這些命令用於查看 BOT 幫助、檢查回應及獲取邀請連結。

## 命令列表
命令名稱 | 概述 | 補充說明
-- | -- | --
/help | 顯示 BOT 說明和命令列表。 | 部分環境還會在尚未訂閱時顯示訂閱指引。
/ping | 檢查 BOT 的回應速度。 | 以毫秒顯示大致回應時間。
/exvoice | 顯示可用 ExVoice 列表的 URL。 | 回覆僅對你可見。
/invite | 顯示邀請連結。 | 回覆僅對你可見。

## /help
顯示 BOT 概述及可用斜槓命令的列表。

```text
/help
```

## /ping
檢查 BOT 的回應速度。

```text
/ping
```

## /dashboard
顯示伺服器控制台的 URL。

```text
/dashboard
```

## /exvoice
顯示可用 ExVoice 列表的 URL。

```text
/exvoice
```

## /invite
顯示 BOT 的邀請連結。

```text
/invite
```
