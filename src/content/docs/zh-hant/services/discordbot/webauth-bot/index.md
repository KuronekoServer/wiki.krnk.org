# Web 驗證 BOT
## 關於 Web 驗證 BOT
Web 驗證 BOT 是使用 hCaptcha 的驗證 BOT。

## 命令列表與使用指南
命令名稱 | 概述 |
-- | -- |
/webauth | 指定用於驗證的身分組，並放置驗證面板。
/check | 查看目前爲驗證設定的身分組。

## 常見問題
> 完成驗證後未獲得身分組，或者發生了錯誤。

:::caution
請確認 Web 驗證 BOT 的身分組位於要授予的身分組之上。
如果設定正確，請[聯繫我們](https://discord.krnk.org)。
:::

![image](https://cdn.krnk.org/kuronekoserver/wiki/webauth-bot/role.webp)

> 顯示「應用程序未回應」或「交互失敗」，或者沒有收到回覆

BOT 可能正在維護或發生了錯誤。請先查看[支援伺服器](https://discord.krnk.org)的 #📢service-アナウンス 頻道確認維護狀態，再透過 #お問い合わせ 頻道告知我們。
