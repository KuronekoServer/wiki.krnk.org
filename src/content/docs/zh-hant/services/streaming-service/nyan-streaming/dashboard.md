:::note
**Nyan Streaming Japan 不支援直播錄製和檔案上傳功能。** 本頁關於錄製和媒體的說明適用於支援這些功能的 Nyan Streaming 服務。
:::


:::note
Nyan Streaming 免費伺服器 `free.nyst.live` 無須註冊控制台即可使用。Nyan Streaming 使用 [dash.nyst.live](https://dash.nyst.live/)，Nyan Streaming Japan 使用 [dash.jp.nyst.live](https://dash.jp.nyst.live/)。請確認適用於所用服務和合約的串流與觀看 URL。
:::


Nyan Streaming 的串流金鑰、錄製、分析、通知和團隊設定可從 [Web 控制台](https://dash.nyst.live/)管理。

:::note
設定和使用情況按**組織（團隊）**管理。登入後，請在左上角選擇要操作的團隊。
:::

![Nyan Streaming 控制台概覽頁面](/images/nyan-streaming/dashboard/overview.png)

首頁可查看當前直播數、總觀眾人數、活躍串流金鑰、錄製儲存使用量、直播伺服器運行狀態和最近活動。

## 按目的查找指南

| 要進行的操作 | 頁面 |
| --- | --- |
| 管理串流金鑰及推流／觀看 URL | [串流金鑰](./stream-keys/) |
| 查找和保存雲端錄製 | [存檔](./archives/) |
| 管理透過 CDN 分發的檔案 | [媒體](./media/) |
| 查看觀眾人數和直播質量 | [分析](./analytics/) |
| 查詢身份驗證、設定變更等操作歷史 | [活動](./activity/) |
| 查看直播節點的在線狀態 | [伺服器運行狀態](./servers/) |
| 報告 JASRAC / NexTone 管理音樂作品的使用 | [音樂使用申請](./music-reports/) |
| 管理成員邀請和權限 | [使用者](./users/) |
| 更改組織、帳單、通知和安全設定 | [設定](./settings/) |

## 左側邊欄

| 選單 | 主要用途 |
| --- | --- |
| **控制台** | 整個組織的直播、觀看和儲存概況 |
| **串流金鑰** | 管理推流憑據、連線 URL 和節目播出 |
| **存檔** | 搜尋、播放、分享、下載和刪除錄製 |
| **媒體** | 上傳和管理 CDN 檔案 |
| **分析** | 實時統計、時間序列統計和身份驗證日誌 |
| **活動** | 組織內操作歷史與審計 |
| **伺服器運行狀態** | 各區域與節點的在線狀態 |
| **音樂使用申請** | 報告 JASRAC / NexTone 管理音樂作品的使用 |
| **使用者** | 管理團隊成員和權限 |
| **設定** | 組織資訊、帳單、通知、安全和 API 金鑰 |
