**活動**是用於追蹤組織內使用者操作和系統事件的審計頁面。

![Nyan Streaming 活動頁面](/images/nyan-streaming/dashboard/activity.png)

## 統計卡片

可查看過去 24 小時的總活動數、身份驗證失敗次數、串流金鑰建立／刪除以及團隊邀請／刪除情況。如出現異常增長，請在下方日誌中檢查執行者和時間。

## 主要記錄事件

- 登入成功／失敗、登出、使用者註冊
- 建立、更新、刪除和重新生成串流金鑰
- 刪除錄製、添加／刪除轉推目標
- 建立／撤銷 API 金鑰、通知測試
- 方案升級／降級
- 成員邀請／刪除／角色變更、設定變更

## 查詢日誌

透過搜尋欄篩選事件或使用者。每行顯示事件、執行者、日期時間以及能夠獲取時的 IP 地址，可透過操作選單打開詳情或標記為已審覈。

可使用**全部匯出**或選取行的**匯出**保存調查資料。如具備刪除權限，也可選擇多行刪除。

:::caution
刪除審計日誌後，將無法再用於調查。通常應先匯出保存後再刪除。
:::

## 發現可疑操作時

1. 記錄事件執行者、日期時間、IP 地址和目標。
2. 與[分析](../analytics/)中的身份驗證日誌覈對時間。
3. 如懷疑金鑰洩漏，請重新生成[串流金鑰](../stream-keys/)。
4. 在[設定](../settings/)和[使用者](../users/)中檢查不需要的會話或成員。
