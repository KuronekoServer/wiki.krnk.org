**分析**可透過實時數值和時間序列資料查看組織內正在直播的流。

![Nyan Streaming 分析頁面](/images/nyan-streaming/dashboard/analytics.png)

## 四個分頁

| 分頁 | 可查看的內容 |
| --- | --- |
| **觀眾** | 活躍直播數、同時觀看人數、總輸入位元率和實時圖表 |
| **按時間** | 指定期間內觀眾人數和直播量的時間序列統計 |
| **性能** | 平均輸入／輸出、按金鑰排名及觀看協議構成 |
| **身份驗證日誌** | 最近推流身份驗證的成功／失敗、使用者、IP 地址和日期時間 |

## 觀眾與流健康狀態

實時圖表為每隔數秒從控制平面獲取的整個組織的資料。在**流健康狀態**中，可比較各金鑰的同時觀看人數、輸入／輸出位元率和使用中的觀看協議。

輸入指主播到伺服器的通信，輸出指伺服器到觀眾的通信。只有輸入為 0 時，請檢查推流來源；只有輸出不增長時，請檢查觀看 URL 或身份驗證設定。

## 性能

可查看各金鑰的輸入位元率排名、HLS / WHEP / RTSP 等連線構成、每個流的平均值和最後更新時間。可用於比較更改推流設定或切換觀看方式前後的情況。

## 身份驗證日誌

用於監控寫入（推流）身份驗證結果。如持續失敗，請檢查串流金鑰、接入機密值、推流 URL 和來源 IP 限制。日誌不會顯示機密值本身。

:::note
沒有直播時，實時數值和排名會為空。如顯示無法連線 API 的錯誤，請先檢查重新加載後問題是否仍然存在，再參閱[故障排除](../../troubleshooting/)。
:::
