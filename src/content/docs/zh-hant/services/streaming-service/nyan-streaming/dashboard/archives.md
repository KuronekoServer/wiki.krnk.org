**存檔**按組織顯示透過串流金鑰錄製的歷史直播。

![Nyan Streaming 存檔頁面](/images/nyan-streaming/dashboard/archives.png)

## 支援錄製的節點

:::caution
**只有 Node02 可以使用錄製功能。**Node01 和 Node03 無法錄製。

- **Node01**：根據與 JASRAC、NexTone 的授權協議，無法向使用者提供錄製資料。
- **Node03**：該節點面向長時間直播，為避免錄製擠佔伺服器儲存容量，不支援錄製。

需要錄製時，請選擇 Node02。即使使用 Node02，訂閱方案也必須提供錄製功能。
:::

## 建立錄製

1. 從**串流金鑰**打開目標金鑰。
2. 在**錄製**分頁中啟用自動錄製。
3. 開始推流。
4. 直播結束並處理完成後，錄製會顯示在存檔中。

錄製功能、整個組織的儲存容量和保留期限取決於方案。請同時查看[方案與限制](../../plans-and-limits/)和[如何選擇節點](../../nodes/)。

## 頁面頂部統計

| 項目 | 含義 |
| --- | --- |
| **總存檔數** | 已錄製的會話數量 |
| **總時長** | 所有錄製時長的合計 |
| **總觀眾人數** | 各會話平均觀眾人數的累計值 |
| **平均時長** | 每個會話的平均錄製時長 |

期間可選擇**全部／過去 7 天／過去 30 天／過去 90 天**。搜尋欄可按標題篩選。

## 錄製操作

每行的操作選單可用於在新分頁觀看、下載、複製直接連結、重新命名和刪除。選擇多行後可批量下載或批量刪除，**全部匯出**可匯出整個列表。

重新命名會更改列表和觀看頁面的顯示名稱，以及下載時的檔案名，但不會改變直接連結 URL。

:::caution
刪除的錄製無法恢復。請先下載需要的錄製，並確認目標標題和開始時間後再刪除。
:::

## 未顯示錄製時

- 確認是否使用啟用了錄製的串流金鑰進行直播。
- 確認推流目標是否為 Node02。Node01 和 Node03 的直播不會錄製。
- 直播剛結束時狀態可能為**處理中**或**待處理**，請等待完成。
- 在[媒體](../media/)中檢查組織儲存是否已達上限。
- 確認左上角選擇了正確的團隊。
