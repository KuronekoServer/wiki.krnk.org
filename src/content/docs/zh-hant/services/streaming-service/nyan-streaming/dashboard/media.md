**媒體**可用於上傳影片、圖片及其他檔案，並透過 CDN 分發。錄製和手動上傳使用同一份組織儲存。

![Nyan Streaming 媒體頁面](/images/nyan-streaming/dashboard/media.png)

## 組織儲存

頁面頂部顯示使用量與上限、剩餘容量、使用率，以及錄製和媒體各自的明細。沒有容量上限的方案僅顯示當前使用量。

達到儲存上限後，新的錄製或上傳會失敗。請刪除不需要的檔案，或先下載所需檔案再整理。

## 上傳檔案

1. 點擊上傳區域，或拖放檔案。
2. 等待進度達到 100%，且狀態變為**就緒**。
3. 在列表中確認名稱、類型、大小和狀態。

單個檔案上限為 **1 GB**。影片處理期間可能無法立即播放。如顯示**失敗**，請檢查容量和網路狀態後重新上傳。

## 上傳後的操作

- 影片可透過播放按鈕檢查內容。
- 重新命名時保留擴展名，僅更改基本檔案名。
- 允許使用英文字母、數字、連字號（`-`）和底線（`_`）。不允許使用空格、日文或其他符號。
- 可刪除不需要的檔案。

:::caution
重新命名媒體後，檔案 URL 也會變化，舊 URL 將失效。請同時更新網站、公告和播放器等處已分享的連結。
:::

:::caution
刪除無法撤銷。請確認沒有正在使用的 URL 後再刪除。
:::
