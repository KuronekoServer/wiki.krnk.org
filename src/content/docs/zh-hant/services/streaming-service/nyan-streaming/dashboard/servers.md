**伺服器運行狀態**根據直播節點發送的心跳，顯示各區域的在線狀態。

![Nyan Streaming 伺服器運行狀態頁面](/images/nyan-streaming/dashboard/servers.png)

## 如何查看

頁面頂部顯示運行中的節點數、已登記的節點總數、區域數和最後更新時間。各區域卡片中可查看每個節點的**在線**或**離線**狀態。因運營原因未公開主機名的區域僅顯示臺數。

點擊**重新整理**可重新獲取最新狀態。無法連線 API 或沒有已登記伺服器時，頁面會顯示相應狀態。

## 如何選擇節點

服務和連線位址請參閱[選擇服務與節點](../../nodes/)。

## 推流前或故障時的檢查

1. 確認要用於推流的區域是否在線。
2. 如離線，請重新加載，並查看 [KuronekoServer Status](https://status.krnk.org/)。
3. 如有其他可用區域，將該區域的推流 URL 設定到 OBS 等軟體。
4. 開始推流後，在[分析](../analytics/)中確認是否收到輸入。

:::note
僅在控制台中顯示或選擇節點，並不會固定連線目標。實際連線目標由輸入直播軟體的 URL 決定。
:::
