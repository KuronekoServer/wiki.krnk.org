**設定**用於管理整個組織的基本資訊、付款、通知、訪問控制和公開 API 金鑰。可更改的項目取決於當前角色。

![Nyan Streaming 設定中的安全分頁](/images/nyan-streaming/dashboard/settings.png)

:::note
圖片展示安全分頁，包含各卡片的底部。團隊 ID、帳單資訊、帳戶刪除等敏感區域未包含在公開圖片中。
:::

## 常規

設定團隊名稱、團隊 URL、大頭貼和**預設語言**。預設語言用於直播限制的郵件、Webhook、控制台通知以及觀看頁面的警告影片。

同一頁面也提供團隊 ID、所有權轉移、退出團隊和刪除團隊操作。除外部整合需要團隊 ID 的情況外，請勿公開。

## 帳單

查看當前方案、付款方式和帳單歷史。更改為付費方案前，需要有效的付款方式。添加、更新和刪除付款方式應由所有者等具備必要權限的使用者執行。

:::caution
帳單頁面可能顯示付款資訊。共享螢幕或螢幕截圖前請確認內容。
:::

## 通知

### 通知目標

可選擇應用內、郵件和 Webhook 通知。保存 Webhook URL 後，可發送普通格式或 Discord embed 格式的測試通知。

### 通知事件

- 直播開始／結束
- 身份驗證失敗
- 觀眾人數里程碑
- 每週報告
- 超過位元率上限
- 連續直播超過 24 小時
- 達到儲存上限

向正式使用的 Webhook 發送測試時，會實際發送通知。請先告知通知接收方的維運人員再執行。

## 安全

- 啟用或禁用雙因素身份驗證。
- 選擇會話超時時長。
- 按 `IP / CIDR` 允許或拒絕推流來源 IP。
- 查看 API 金鑰管理頁面的連結及 API 速率限制。

IP 規則按從上到下的順序評估，應用首個匹配規則。預設行為為允許。

:::note
IP 限制僅適用於推流（publish）。不提供針對公開觀看的 IP 限制。
:::

## API 金鑰

可指定金鑰名稱和可選的有效期，建立公開 API 金鑰。列表中可查看建立日期、最後使用日期和有效期，並撤銷不需要的金鑰。

:::caution
金鑰本體僅在建立後顯示一次。請保存到安全的位置，勿粘貼到聊天或公開儲存庫中。洩漏時請立即撤銷並重新建立。
:::

API 頁面也顯示身份驗證請求標頭和端點說明。詳情請參閱[公開 API](../../api/)。

## 所有權轉移、退出與刪除

這些操作影響範圍較大。請確認目標團隊、接收方、當前角色和帳單狀態，並保存必要的串流金鑰、錄製和審計日誌後再執行。
