**串流金鑰**用於建立、輪換和刪除推流憑據，以及查看可提供給觀眾的 URL。

![串流金鑰列表與節目播出](/images/nyan-streaming/dashboard/stream-keys.png)

## 建立金鑰

1. 打開左側選單的**串流金鑰**。
2. 選擇**新建金鑰**，指定名稱和方案。
3. 按需設定觀看金鑰、節點、區域和備註。
4. 打開已建立的金鑰，確認推流 URL 和觀看 URL。

觀看金鑰留空時會隨機生成。如需自訂值，請使用英文字母、數字、連字號（`-`）和底線（`_`）。接入機密值始終隨機生成。

不確定節點用途時，請參閱[如何選擇節點](../../nodes/)。沒有特殊要求時，請選擇標準 Node02。

:::caution
接入用串流金鑰等同於密碼。不要讓其出現在螢幕截圖或直播畫面中，也不要與第三方分享。洩漏時請**重新生成金鑰**，立即使舊值失效。
:::

## 推流與觀看地址

金鑰的**概覽**中可查看所選節點對應的以下資訊。

| 用途 | 顯示內容 |
| --- | --- |
| 推流 | RTMP、WebRTC（WHIP）、RTSP 接入 URL 和接入路徑 |
| 觀看 | RTSP、RTSPT（TCP）、WebRTC（WHEP）、HLS、RTMP 觀看 URL |
| 限制 | 組織合計的位元率與觀眾上限、錄製與轉推、儲存及地區限制 |

在頁面上選擇節點並不會固定推流目標。實際連線目標由輸入 OBS 或播放器的 URL 決定。

## 金鑰詳情分頁

| 分頁 | 內容 |
| --- | --- |
| **概覽** | 推流／觀看 URL、方案、上限和可用功能 |
| **瀏覽器推流** | 透過 WebRTC（WHIP）直播攝影機、麥克風或螢幕 |
| **瀏覽器觀看** | 透過 WebRTC（WHEP）低延遲觀看 |
| **HLS 觀看** | 在控制台內檢查 `.m3u8` |
| **統計** | 整個金鑰和各節點的實時統計 |
| **錄製** | 啟用 Node02 自動錄製，以及此金鑰的錄製列表 |
| **轉推** | 管理 YouTube、Twitch 等外部 RTMP 目標 |
| **均衡器** | EQ 與混響設定 |

EQ 提供 Flat / Voice / Music / Bass Boost / Treble Boost 預設，混響提供 Studio / Room / Hall / Cathedral 預設。更改會在約 3 秒內反映到觀看端。

:::note
只有 Node02 可以使用錄製功能。Node01、Node03 不支援錄製的原因及使用條件，請參閱[存檔](../archives/#支援錄製的節點)。
:::

## 節目播出（頻道）

Pro 及以上方案可切換透過組織共用觀看 URL 播出的串流金鑰。這是一個保持觀眾連線、僅替換推流來源的直播切換器。

- 選擇金鑰，或選擇**停止播出**。
- 切換在新金鑰的下一個關鍵影格生效，最多會發生 1 GOP 時長的短暫中斷。
- 切換前後請使用相同的解析度、影格率、編解碼器和音訊設定。

## 金鑰被暫停時

超過位元率上限、連續直播 24 小時或違反服務條款時，列表會顯示狀態和預計解除時間。警告畫面及恢復方法請參閱[故障排除](../../troubleshooting/)。
