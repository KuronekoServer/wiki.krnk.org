**使用者**用於管理組織成員、權限、邀請狀態和最後活躍時間。

## 如何查看頁面

頁面頂部顯示總成員數、管理員數和待處理邀請數。在**全部成員**中，可透過姓名或郵件地址搜尋，並查看角色、狀態和最後活躍時間。

:::note
為避免公開成員姓名和郵件地址，本頁未提供螢幕截圖。以下說明頁面結構和操作。
:::

## 角色

| 角色 | 權限範圍參考 |
| --- | --- |
| **所有者** | 完整訪問權限，包括帳單、所有權轉移和組織刪除 |
| **共同所有者** | 除所有權轉移和組織刪除外的幾乎所有操作 |
| **成員** | 對串流金鑰和分析的唯讀訪問 |

請分配滿足需求的最低權限角色。僅將負責更改直播設定或通知的人員設為管理員。

## 邀請成員

1. 點擊**邀請成員**。
2. 指定被邀請者的郵件地址和角色。
3. 發送後，確認狀態變為**已邀請**。
4. 對方加入後，狀態變為**活躍**。

待處理邀請可從操作選單重新發送或取消。

## 更改角色和移除成員

可從各成員的操作選單更改角色。移除成員後，該使用者將無法訪問組織的串流金鑰、錄製、分析和設定。

:::caution
人員交接或離職時，除移除成員外，還應考慮重新生成或撤銷曾分享的串流金鑰和 API 金鑰。請勿移除最後一名所有者。
:::
